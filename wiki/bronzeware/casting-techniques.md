# 青铜器铸造工艺

> 背景知识库。本文梳理范铸法、失蜡法及装饰工艺（错金银、鎏金），每节含技术要点、代表器与学术分歧。
> 标签：`[中文学界主流]` / `[海外学界主流]` / `[新近争论]`。

中国青铜器与同时期西亚、欧洲青铜器最根本的工艺分野，在于中国以**陶范（泥范）铸造**为主流体系，而非锤揲（锻打）或失蜡。这一选择不仅是技术问题，更塑造了中国青铜器"重铸造、重纹饰、重组合"的整体面貌。

---

## 一、范铸法（陶范法 / 泥范法）

范铸法是商周青铜器的绝对主流。基本流程：制**模**（实物原型）→ 翻**外范**（分块翻制带阴纹的外壁）→ 制**芯（范芯）**→ 外范与范芯之间留出器壁厚度的空腔 → 灌注铜液 → 脱范、打磨。

### 1. 块范法（合范法）
器壁较大或带复杂花纹者，外范须分成数块（"块范"），刻好阴纹后再合拢。块与块的接缝在器表会留下凸起的**范线（铸缝）**，常被工匠顺势处理成**扉棱**（如方鼎四隅与中线的齿状凸脊）。范线与垫片痕是鉴定真伪、判断工艺的重要依据。
- 技术要点：分范越多、花纹越能做满；"三层花"（雷纹地纹 + 兽面主纹 + 细部刻线）即靠精细分范实现。
- 代表器：后母戊鼎（`houmuwu_ding`）、妇好系列礼器（`fuhao_gui`、`fuhao_xiaozun`）。

### 2. 浑铸法（一次浇铸）
器身一次浇成，是最常见的方式，适合形体相对单纯的器物。
- 代表器：多数商周圆鼎、簋。

### 3. 分铸法（铸接 / 二次铸造）
先单独铸出附件（耳、足、提梁、兽首等），再将其嵌入主体范中浇铸主体使之连为一体（"铸接"）；或反之先铸主体、再铸接附件。分铸使复杂立体造型成为可能。
- 技术要点：可见明显的铸接界面与铜质差异。
- 代表器：曾侯乙尊盘的镂空附件、许多带繁复提梁的卣（如 `fuhao_you_owl`）、龙虎尊（`longhu_wen_zun`）类高浮雕器。

### 范铸法 · 学术分歧
- `[中文学界主流]` 强调块范法是中国独立发明并长期独占主流，是中华青铜文明的技术身份标志。
- `[新近争论]` 关于"为何中国独走陶范路线"，一说源于发达的高温制陶传统（陶窑、陶范一脉相承）；另一说与"礼器需大批量、标准化、可复制花纹"的社会需求有关——是**社会需求选择了技术**，而非技术决定社会。

## 二、失蜡法（熔模法）

以蜡（或油脂、松香）做出可带极复杂镂空与悬浮结构的蜡模，外敷耐火泥料，加热使蜡熔流而出，形成空腔，再灌铜。失蜡法能实现范铸法难以完成的**透雕、镂空、互不接触的悬浮构件**。

### 技术要点
蜡模一次性消耗（"熔模"），故每件器物的蜡模都独一无二，适合孤品精工；但不利于批量与标准化，这与商周礼器的大规模生产取向相左，可能是它长期未成主流的原因之一。

### 代表器
- **河南淅川下寺楚墓"云纹铜禁"**（春秋中晚期，1978 年出土）。
- **湖北随县曾侯乙墓尊盘**（`zenghouyi_zunpan`，战国早期），其繁密镂空附饰常被举为失蜡法典范。

### 失蜡法 · 学术分歧（重点争议）
- `[中文学界主流·传统说]` 中国失蜡法约始于**春秋中晚期**，云纹铜禁、曾侯乙尊盘为最早实证，独立发明。
- `[新近争论·范铸说]` 周卫荣、董亚巍等学者通过工艺复原，主张云纹铜禁与曾侯乙尊盘**实为范铸（分铸 + 焊接 + 失蜡式陶范的组合）**而非真正失蜡法，理由是：若先秦已掌握成熟失蜡法，何以"萌芽—发展—消亡"在历史上几乎不留痕迹（汉至唐文献才明确记载，《唐会要》记武德年间铸开元通宝用失蜡法）。
- `[海外/折中]` 另有学者承认尊盘附件用了失蜡，但强调它是范铸传统内部的"创新升华"，非外来。此争论至今未有定论，是中国冶铸史最热的公案之一。

## 三、错金银（金银错）

在已铸成的铜器表面预留（铸或錾刻）凹槽，将金银丝/片嵌入槌实，再磨错（打磨）平整，使金银花纹与铜地齐平、光亮如绘。盛行于春秋晚期至汉代。
- 技术要点：先有"图案模铸出凹槽"或"成器后錾槽"两路；嵌入后须反复磨错才显光泽。
- 代表器：错金银云纹犀尊（`cuojin_xiyun_xizun`）、错金银鸟篆纹壶（`cuojinyin_niaoshu_tonghu`）、错金博山炉（`cuojin_boshanlu`）、错金银几何纹方鉴（`cuojin_jihewen_fangjian`）。
- 分歧：错金银的兴起被一些学者视为青铜"由神圣礼器转向世俗奢侈品"的物质标志（`[海外学界主流]` 罗森等的"礼制变革后审美世俗化"思路）；中文学界则更多从工艺谱系本身讨论其与镶嵌（绿松石镶嵌）的源流关系。

## 四、鎏金（火镀金 / 汞齐法）

将金溶于水银成"金汞齐"，涂于铜器表面，加热使水银蒸发，金附着于器表，再压光。可使整器或局部呈现华贵金色。盛行于战国至汉、并延续至后世。
- 技术要点：汞剧毒、易挥发，工艺危险；"一斤金一斤汞"的配比见于后世文献。
- 代表器：长信宫灯（`changxin_gongdeng`，鎏金）、鎏金铜马（`maoluling_liujinma`）、南越王鎏金壶（`nanyuewang_liujinhu`）、东汉鎏金博山炉（`liujin_boshanlu_donghan`）。
- 分歧：鎏金的起源时间随新出土材料不断上提，目前多定在**战国中晚期**；个别更早的"鎏金"报道因检测手段差异（鎏金 vs 贴金 vs 涂金）而存疑，故"中国鎏金始于何时"仍随科技检测精度而被修正。

## 工艺演变的大势

商周以**范铸 + 满工纹饰**树立礼器威严 → 春秋战国以**失蜡（或范铸创新）+ 错金银 + 鎏金**追求精巧华美 → 秦汉青铜走向**素面日用 + 镀金装饰**。工艺史的转向，与青铜器从"通神之礼器"到"世俗之美器"的功能转变互为表里。
