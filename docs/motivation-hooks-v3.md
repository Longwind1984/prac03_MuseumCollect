## 0. 设计原则: 6 种动机类型 (沿用 v1)

| 类型 | 心理机制 | 视觉化策略 |
|------|---------|-----------|
| **Completion 完成感** | Zeigarnik effect | 空白格 / 灰色剪影 / 进度条 |
| **Connection 关联感** | 知识网络扩张快感 | 节点连线 / 跨视图跳转 |
| **Rarity 稀有感** | 拥有别人没有的 | 光晕 / 印章 / 显著边框 |
| **Story 故事解锁** | 叙事好奇心 | 拼图揭示 / 长卷解锁 |
| **Identity 身份认同** | 自我标签强化 | 称号 / 段位 / 个性化档案 |
| **Spatial/Temporal Completion 时空完整** | 地图全开 / 时间线全亮 | 朝代柱填满 / 古国全踏足 |

**避免**: 单纯的"积分 + 徽章 + 排行榜" (Skinner box) — 博物馆爱好者反感游戏化外壳, 欢迎游戏化内核。

**v3 红线** (基于 v1 Motivation Auditor 反馈):
- ❌ 不做 "差 N 件 解锁 X" 红字紧迫感
- ❌ 不做"国宝率 100% (行业 4%)" 等 vanity metric
- ❌ 不做 XP-shaped HUD (头条数字栏)
- ✅ 每页最多 1 个 "almost there" callout, 必须在用户刚 action 后出现, 语言为"您 当前 可 选择 的 研究 方向 →"

## 1. 各维度的动机 Hook (7+1)

### 1.1 形制 (Pokédex + 实景照片 + 同型对照墙)

| Hook 类型 | 具体机制 |
|----------|---------|
| **Completion** | 同子型集齐 (如"方尊"4 件) → 解锁"该子型进化时间线" |
| **Connection** | 同型对照墙的视觉冲击 — "原来方尊有这么多变体" |
| **Identity** | "鼎类大师 / 觚的鉴定家" 类别专精称号 (基于该子型收藏占比) |
| **Story** | 集齐九鼎八簋 → 解锁"列鼎制度·天子之礼"故事卷 (与§1.6 用途联动) |
| **Rarity** | 罕见形制 (如龙形觥, 唯一存世) 单独标"孤型" 小章 |

**具体诱发场景**:
```
用户在形制谱系树点"方尊", 弹出对照墙:
  [四羊] [龙虎] [妇好] [?? 待补]
   ████   ████   ████   ──────

  右下小字: "再 收 1 件 方尊 → 解锁 方尊进化时间线"

  (注意: 不是红字, 不是紧迫感, 是平静的研究方向提示)
```

**判定指标**: 对照墙浏览 → 该子型 catalog filter 跳转的转化 > 25%

### 1.2 时代 (时代柱重做)

| Hook 类型 | 具体机制 |
|----------|---------|
| **Temporal Completion** | 时代柱段位填充, 空白段呼吸动效诱发"为什么我没有西周中期" |
| **Completion** | 子分期颗粒度 (商早/中/晚 拆开) — 空白更精细 |
| **Identity** | "商代主义者 / 周礼派 / 战国发烧友" (基于用户主要收藏时代) |
| **Story** | 点朝代段 → 解锁"该时代故事卷" (5-8 件代表器物的串联叙事) |
| **Connection** | 用户收藏在时代柱形成"密度热力" — 一眼看到自己关心哪个时代 |

**具体诱发场景**:
```
用户打开时代柱:
   商晚期 ████████████████ (22 件)
   西周早 █████░░░░░░░░░  (5 件)
   西周中 ░░░░░░░░░░░░░░  (0 件 ← 缓慢呼吸闪烁)
   西周晚 ███████░░░░░░░  (7 件)

   西周中期段的悬停文案:
   "穆王 / 恭王 / 懿王 时代, 您 当前 收藏 0 件.
    推荐 起点: 大克鼎 (周孝王, 上海博物馆)"
```

**判定指标**:
- 时代柱平均停留 > 8s
- 空白段点击 → 搜索/详情转化 > 15%

### 1.3 地理 (真实地形 + 古国 overlay + 双 view)

| Hook 类型 | 具体机制 |
|----------|---------|
| **Spatial Completion (出土 view)** | 全国遗址点 + 海外馆点, 空白点呼唤 |
| **Spatial Completion (馆藏 view)** | 9 大馆 + 海外馆"印章本" — 用户去过 = 真实到过博物馆 |
| **Identity** | "考古足迹"称号 — "三大文明区朝圣者" (殷墟+周原+三星堆) |
| **Rarity** | 三星堆/盘龙城等独立文明遗址点 = 金色徽章 |
| **Story** | 每个遗址有"考古故事" — 妇好墓 1976 发掘 / 三星堆 1986 祭祀坑 |
| **Connection** | 同遗址多件文物 → "同坑兄弟" 跳转 |
| **Story (海外)** | 流散文物 timeline (圆明园流散 / 八国联军 / 抗战转移), 情绪驱动 |

**具体诱发场景**:
```
用户切到"海外流散" view:
   地图扩展到全球, 中心从中国移到欧美.
   大都会博物馆 (MET): 周代鸮卣 ★
   大英博物馆: 商代大鼎 ★
   弗利尔美术馆: 西周毛公鼎拓本

   每件配 timeline:
   "1860 圆明园流散 → 1872 私人收藏 →
    1942 捐赠 弗利尔 → 至今 D8 展厅"

   右下角小注 (不大字): "本应在家"

   底部许愿: [♡ 我也希望它回家] (社交分享 hook)
```

**判定指标**:
- 地理月活 > 60%
- 海外馆藏点位查看率 > 30%
- "我也希望它回家" 分享率 > 5%

### 1.4 纹饰 (演化树 + 15-25 SVG icon + 拓片本)

| Hook 类型 | 具体机制 |
|----------|---------|
| **Identity ★** | "凤鸟收藏家 / 饕餮鉴定师 / 窃曲修士" — 最响亮的身份感 |
| **Connection** | 拓片本可独立收藏 — 同纹饰跨器物的"纹饰家族" |
| **Story** | 演化树本身就是故事: 神权 (饕餮) → 礼制 (窃曲) → 写实 (凤鸟) |
| **Completion** | 演化树分支末梢 — 该分支所有节点点亮 |
| **Rarity** | 罕见纹饰 (鸱鸮纹·妇好系) 单独 SVG icon + 金边 |

**v3 升级**: 每个纹饰有独立 SVG icon (而非 v1 的灰色圆点), 用户可视化记忆纹饰

**具体诱发场景**:
```
用户收藏 8 件器物 → 6 件含夔龙纹.
系统自动判定 → 称号: "夔龙派 一初"
弹小卡:
  "您 在 8 件 收藏 中 已 6 件 含 夔龙纹.
   再 识 12 种 夔龙变体 (顾首/双身/抽象化等) →
   可 升级 为 '夔龙派 大宗'"

  拓片本中整齐排着 6 张黑白拓片, 收集欲被激活.
```

**判定指标**:
- 纹饰称号系统的解锁率 > 40%
- 拓片本访问频次 > 3 次/月/用户
- SVG icon 在 catalog filter chip 上的使用率 > 25%

### 1.5 铭文 (字字交互 + 段位 + 何尊长卷)

| Hook 类型 | 具体机制 |
|----------|---------|
| **Identity ★★** | 段位制 "初窥 → 入门 → 一段 → 二段 → 鉴师 → 大宗师" |
| **Completion** | 累计识字 / 已知金文总数 (~3700), 长期目标 |
| **Connection** | "若"字在 7 件器中出现 → 跨器物字轨迹 |
| **Story ★** | 何尊长卷"中国"二字 → 学术 wow moment |
| **Rarity** | 史诗铭 (300+ 字) 国宝特别标记 |

**v3 升级**: 何尊长卷专题 + JINWEN_DICT 从 20 字扩到 200 字

**具体诱发场景** (何尊长卷):
```
用户首次打开何尊详情 → 自动弹"何尊长卷专题"邀请:
  "何尊 全文 122 字, 包含 '中国' 二字 最早 实物 出处.
   预计 阅读 时间 12 分钟. [开始]"

进入长卷:
  全屏横向卷轴, 右滑.
  逐字浮出: 王 唯 五 月 既 望 ...

  到第 13-14 字: 中 国
  画面停顿, 朱砂圆圈框出此两字, 放大:
  "宅 兹 中 或" → "居 于 中央 之 邦"
  → 这 是 '中国' 二字 第一次 落 在 青铜上.
  时代: 西周成王早期, 距今 约 3050 年.

  完成长卷 → 称号: "宅兹中国·见证者"
  解锁: 何尊"中国"二字壁纸下载.
```

**v3 段位机制修正** (v1 anti-Skinner 问题):
- v1: 单纯按字数 → 段位 → 鼓励快速 hover 刷字数
- v3: 段位 = (识字数) × (在不同器物上出现的次数), 鼓励横向阅读

**判定指标**:
- 何尊长卷完成率 > 30%
- 重度铭文用户 (识字 > 100) 月活率 > 80%
- "宅兹中国·见证者" 称号分享率 > 20%

### 1.6 用途 / 礼制 (场景重建 + 5 套场景 + 等级判定)

| Hook 类型 | 具体机制 |
|----------|---------|
| **Spatial Completion** | 多套场景, 缺位的器物剪影显示在场景中 |
| **Story** | 礼制故事 — 集齐九鼎才解锁"周礼·王道篇" |
| **Identity** | "礼器派 / 酒器派 / 乐师 / 武士" 用途专精称号 |
| **Connection** | 场景中器物 → 跳到详情, 场景是导航器 |
| **Completion** | 单场景完成度百分比 + 等级判定 (天子/诸侯/卿大夫/士) |

**v3 升级**: 5 套场景 (太牢/燕飨/朝聘/军礼/葬礼) + 等级判定 banner

**具体诱发场景** (等级判定):
```
用户在"太牢祭祀"场景中归位:
   [3 鼎] [2 簋] [1 觚] [0 尊]

   顶部 banner 自动判定:
   "当前 等级: 士之礼 (3 鼎 2 簋)
    距 卿大夫之礼 (5 鼎 4 簋): 再 2 鼎 2 簋
    距 诸侯之礼 (7 鼎 6 簋): 再 4 鼎 4 簋
    距 天子之礼 (9 鼎 8 簋): 再 6 鼎 6 簋"

   (语言是"研究方向", 不是紧迫红字)
```

**判定指标**:
- 场景完成度 ≥ 50% 用户次月留存 > 70%
- 切换不同场景比率 > 40%
- 等级判定 banner hover 率 > 60%

| Hook 类型 | 具体机制 |
|----------|---------|
| **Story ★** | 每位铸主背后的人物故事 (《史记·列传》体例) |
| **Completion** | 同铸主作品收藏率 — 妇好 12 件全集是高难度长期目标 |
| **Connection** | 关系图谱 — 器物收藏延伸到人物收藏 |
| **Identity** | "妇好系列收藏家 / 周王作器人 / 曾侯乙乐工" |

**v3 升级**: D3 force-directed graph 替代 v1 静态 ASCII

**具体诱发场景** (关系图谱):
```
用户在妇好档案点"查看关系图谱":
   节点: 武丁 — 妇好 — 祖庚 — 祖甲 — ...
   边: 夫妻 / 父子 / 君臣

    武丁 的 4 件 传世器 中, 您 已 收藏 0 件.
    建议 起点: 武丁卜辞鼎 (国博)"
```

**判定指标**:
- 铸主档案二次访问率 > 50%
- D3 关系图谱平均停留 > 20s
- 妇好/曾侯乙等"全套"目标的进度 > 30% 用户比例 > 5%

### 1.8 ★ 稀有度 (全局视觉层)

| Hook 类型 | 具体机制 |
|----------|---------|
| **Rarity ★★** | 全局视觉系统, 渗透所有维度视图 |
| **Identity** | 国宝率(自我对照, 不做行业 vanity comparison) |
| **Story** | 每件禁出境国宝有"国之重器"叙事 (为何被列入 195 名录) |
| **Connection** | 同稀有度文物的"亲缘视图" — 4 件商代禁出境鼎并排 |

**具体诱发场景** (首件禁出境国宝):
```
用户首件禁出境国宝入藏:
   卡片金光乍现, "国之重器" 朱砂章入框动画.
   全屏 3s 庆祝:
   "您 的 第 1 件 禁止出境 国宝 — 这 是 国家 不 允许 出境 的 级别.
    全球 收藏家 都 在 等 看到 它."

   底部分享 CTA: [告诉 朋友 您 的 国宝] (天然 social moment)
```

**v3 anti-Skinner 修正**:
- v1: "国宝率 100% (行业平均 4%)" → 删, vanity metric
- v3: "您 的 195 件 禁出境 进度 12/195" (clean fact, no comparison)

**判定指标**:
- 首件禁出境后 7 日分享率 > 30%
- 用户每月新增禁出境平均 > 0.5 件 (说明 catalog 推荐有效)

## 2. 跨维度组合 Hooks (5 组)

### 2.1 组合 A: 时代 × 地理 × 纹饰 三联动 ★★

(在 `dimensional-map-v3.md §8.1` 已 spec)

**Hook 类型**: Connection × Spatial × Temporal (三类叠加)

**强度爆点**: 用户 hover 商晚期 → 同时看到地图上殷墟+三星堆+盘龙城点亮 + 演化树饕餮夔龙节点闪光 → 一次"我看到了三千年前的中国全景"的认知冲击

**称号解锁**: 用户同时收藏 "商晚期 + 三星堆" 任意 1 件 → "二重文明 见证者"

---

### 2.2 组合 B: 形制 × 纹饰 — "这型主流是什么纹"

(在 `dimensional-map-v3.md §8.2` 已 spec)

**Hook 类型**: Connection × Story

**触发场景**: 用户点"方尊" → 弹"饕餮 65% / 夔龙 40% / 凤鸟 12%" → 用户理解"原来方尊都偏好这些纹"

**称号解锁**: 用户收藏 5 件方尊 (含全部 3 种主流纹饰) → "方尊纹饰鉴别师"

---

### 2.3 组合 C: 铸主 × 铭文 — 字→人→物 全链

(在 `dimensional-map-v3.md §8.3` 已 spec)

**Hook 类型**: Connection × Identity

**触发场景**: 释读铭文识别"毛公"二字 → 弹毛公档案 → 用户从字看到人, 从人看到物

**称号解锁**: 在铭文中识别出 5 位不同铸主 → "金文铸者档案家"

---

### 2.4 组合 D: 用途 × 形制 — 礼制完整性引擎 (沿用 v1)

**Hook 类型**: Completion × Story 双重

**触发场景**: 在太牢场景归位 → 形制谱系树同步点亮 → 集齐九鼎八簋解锁"天子之礼"

---

### 2.5 组合 E: 稀有度 × 全维度 — 全局光晕 (沿用 v1)

**Hook 类型**: Rarity 全局乘数

**机制**: 稀有度不是独立组件, 而是叠加层 — 在每个维度视图里, 国宝以金光区分

## 3. 反 Skinner 设计纪律 v3 (基于 v1 audit fix)

### 3.1 明确不做(v3 红线)

| 不做 | 替代方案 |
|------|---------|
| ❌ 每日签到积分 | ✅ 每日"金文鉴读"挑战 (识 5 字累计入段位, 但 0 字也不会失) |
| ❌ "差 N 件 解锁 X" 红字紧迫感 | ✅ "您 当前 可 选择 的 研究 方向 →" 平静推荐 |
| ❌ 单纯排行榜 | ✅ "您 的 收藏 风格 分析" 自我对照 |
| ❌ "国宝率 100% (行业 4%)" vanity metric | ✅ "您 的 195 件 禁出境 进度 12/195" clean fact |
| ❌ XP-shaped HUD 头条数字栏 | ✅ "本周 您 主要 关注 西周 中期" 行为叙述 |
| ❌ 体力/疲劳值/广告 | ✅ 0 营销机制, 纯内容驱动 |
| ❌ 抽卡机 | ✅ 必须基于真实收藏 (拍照/馆内确认/学术录入) |

### 3.2 "Almost there" Callout 规则

- 单页最多 **1 个** "almost there" callout
- 必须在 "用户 刚 做了 action 之后" 触发 (不在 first load)
- 语言: "您 当前 可 选择 的 研究 方向 → 大盂鼎 (西周早期, 含 您 未识字 78 个)"
- 不允许: "再 3 件 解锁 X" / "差 N 字 升段"

### 3.3 称号系统是隐线, 不是显线

- ❌ 不做"成就墙"页面
- ✅ 称号出现在: 用户头像旁角标 / 分享卡片水印 / 收藏列表元数据
- ✅ 用户主动想看才看到全部称号 (折叠在个人页"我的称号" tab)

### 3.4 核心信念

**博物馆爱好者反感"游戏化外壳", 欢迎"游戏化内核"。** 差别在于: 游戏化机制是否服务于内容本身的探索。

## 4. 用户旅程: Day1 → Year1 (300 件规模)

### 4.1 Day 1 (新手 0 → 1 件)

**Trigger**: 用户拍照识别第一件器物, 或从"明星器物"试试卡选 1 件

**多维同时点亮的视觉爆发**:
```
扫描成功! 1 秒内, 同时点亮:
  ▸ 时代柱: 该朝代段 +1 像素填充
  ▸ 地理地图: 该出土点亮起
  ▸ 形制谱系: 该子型新分支
  ▸ 纹饰演化树: 该纹饰节点 +1
  ▸ 用途场景: 该礼器位入位
  ▸ 铸主档案: 该铸主 +1 件
  ▸ 稀有度: 卡片金光 (如是国宝)

全屏 2s 庆祝:
"一件 器物, 7 个 维度 同时 被 点亮.
 您 已 开始 您 的 青铜 之 路."
```

**称号**: "踏上青铜之路"

**预期行为**: 用户被"7 维度同时活了"的视觉打到, 立刻想试第 2 件

---

### 4.2 Week 1 (1 → 5 件)

**进度**: 每个维度都有部分进度, 用户开始看到自己的"收藏画像"

**关键 hook**:
- 时代柱: 用户的收藏开始形成"密度" (例如商晚期 3 件 + 西周 1 件 + 1 件其他)
- 称号: "初识三代" (覆盖 3 个朝代)
- 称号: 出现首个 "派系" 倾向标签 (如"商代派 萌芽")

**行为预期**:
- 用户每天打开 1-2 次, 平均 5-10 分钟
- 开始 use 维度页面而非只看 catalog

---

### 4.3 Month 1 (5 → 30 件)

**进度**: 第一波时代柱 + 地理地图覆盖, 跨维度组合开始触发

**关键 hook**:
- 时代柱: 接近覆盖 5+ 朝代
- 地理: 三大文明区 (殷墟+周原+三星堆) 中至少 2 个点亮
- 形制: 至少 2-3 个子型出现"集齐 N/4" 提示
- 纹饰: 拓片本 5-10 张, 首个纹饰称号 ("夔龙派 一初")
- 跨维度组合: 首次触发"二重文明 见证者" (商晚期 + 三星堆)

**称号**: "三代见习 / 二重文明见证者 / 派系初步"

**行为预期**:
- 周活 90% (一周打开 ≥ 4 次)
- 平均收藏 5 件/月
- 开始 use 跨维度组合视图

---

### 4.4 Month 3 (30 → 80 件)

**进度**: 多维度进阶称号开始集齐, 铭文段位起飞

**关键 hook**:

**称号**: "国宝学徒 / 金文一段 / 派系大宗"

**行为预期**:
- 月活 80%
- 平均收藏 15 件/月 (热情期)

- 曾侯乙 8 件全集进度 5/8

## 5. 反馈循环 (Feedback Loops) v3

### 5.1 Hot Loop (秒级)
- 扫码识别一件 → 7 维度同时点亮
- 字字悬停 → 立即识别 + 段位累计 +1
- 拓片框选 → 即时拓片入收藏
- hover 时代柱 → 三联动 (时代 × 地理 × 纹饰)

### 5.2 Mid Loop (分钟-小时级)
- 浏览谱系树看到自己的进度
- 切换到铸主档案看到关联人物
- 跨维度组合视图发现新关联

### 5.3 Cold Loop (天-月级)
- 段位升级 (识字段位 / 朝圣段位)
- 称号解锁 (饕餮鉴定师等)
- 解锁特殊视图 (天子之礼 / 何尊长卷)
- 跨维度组合首次触发

### 5.4 Yearly Loop (年级)
- 195 件禁出境国宝全集 (1-2 年)
- 金文 "大宗师" 段位 (1000+ 字)
- 9 馆朝圣印章全集

### 5.5 设计原则

**梯度设计**: 短反馈支撑日活, 中反馈支撑周活, 长反馈支撑年留存。每层都有, 缺一不可。

**v3 强调**: 中反馈 (跨维度组合) 是 v1 最缺的, v3 必须补足。

## 6. 300 件规模下的"密度产生动机" ★ (v3 新增)

> 这是 v1 没考虑的: 25 件知识库时, "完成" 是默认假设 (用户大概率全集)。300 件时, "完成" 变成长期目标, 产品逻辑需重新设计。

### 6.1 知识密度 → 动机密度

300 件 = 中国青铜器学界教学基础范围。在这个规模下:
- 用户**不可能短期全集** (单件 30 分钟阅读, 300 件 = 150 小时)
- 但每件深度内容 (11 字段 + 1-3 张图 + 关联文物) 足够支撑用户"长期游走"
- 关键: 用户每次打开 App, 都有"今天看哪一件" 的好奇心

### 6.2 v3 推荐策略

1. **"今日推荐"** (轻策展)
   - 每天首页推 3 件: 1 件已收藏的"再读" + 1 件相邻的"新探索" + 1 件本周"明星"
   - 推荐算法基于用户收藏画像 (主时代/主形制/主纹饰)
   - 不做"必须打开" 推送, 只在首页柔性显示

2. **"研究路径"** (引导深入)
   - 当用户收藏 ≥ 10 件 → 系统提示一条"研究路径"
   - 例如: 您 已 收藏 5 件 商晚期 鼎. 探索 路径 →
     - 妇好墓 5 件鼎组 (同墓器物群)
     - 商周鼎制度演变 (跨时代纵向)
     - 司母戊鼎 vs 司母辛鼎 (同主对照)
   - 用户主动选路径, 不强推

3. **"集锦"** (主题策展)
   - 系统编辑的"主题集锦": 妇好墓系列 / 三星堆 / 曾侯乙编钟组 / 海外流散十珍
   - 用户可"订阅" 某主题, 该主题相关器物推荐到首页
   - 这是把 300 件密度变成"多个 30-50 件子集" 的策略

4. **"留白态" 提示**
   - 用户收藏 100 件后, 看到 "您 已 覆盖 商代 60%, 西周 40%, 春秋 战国 各 20%"
   - 提示: 是否要在某朝代深耕, 还是横向覆盖?
   - 不强迫, 只提供视角

### 6.3 反"密度疲劳"

300 件密度可能让用户疲劳 (信息过载)。v3 应对:
- 默认隐藏"全集" 进度数字 (避免 vanity)
- 主页只显示 "您 主要 在 XXX" 一行行为叙述
- "我的收藏" 默认按时间倒序, 不按完成率
- 每件文物默认折叠 (Hero + 5 维度卡片), 用户主动展开 accordion

## 7. 给 Visualization Designer 的关键提示 v3

1. **称号系统是隐线, 不是显线** — 不做"成就墙"页面, 称号挂在用户头像旁角标和分享卡片水印
2. **进度可视化优先于数字** — "您点亮了商代 60%" 不如直接看时代柱填了 60%
3. **稀有度是渗透的, 不是独立的** — 不做"国宝列表"页面, 让金光在每个维度视图里闪
4. **空白比填满更重要** — 维度视图必须给用户看到自己的空白, 这是诱发的本源
5. **组合视图比单视图重要** — Phase B 必须 ship 至少 1 个跨维度组合 (推荐时代 × 地理 × 纹饰)
6. **"今日推荐" + "研究路径" + "集锦"** 是 300 件密度下的产品策略, 必须落实
7. **0-state 设计** — 新用户首次访问的 onboarding 3 屏 carousel (来自 v1 audit 推荐)
