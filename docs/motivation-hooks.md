# Motivation Hooks — 青铜器

> Domain Researcher 产出 · Phase 1 of Night Run D0
> 配套文档: `dimensional-map.md` (10 个维度的形态化设计)
>
> 这份文档把每个维度从"信息容器"转化为"持续使用动机"。
> 核心论点: **维度本身 = 动机来源**,不另搞积分排行榜体系。

---

## 0. 设计原则: 6 种动机类型 (Hook Taxonomy)

我们用 6 种动机类型,每个维度至少命中其中 2-3 种:

| 类型 | 心理机制 | 视觉化策略 |
|------|---------|-----------|
| **Completion 完成感** | Zeigarnik effect — 未完成的事情留在记忆中 | 空白格 / 灰色剪影 / 进度条 |
| **Connection 关联感** | 知识网络的扩张快感 | 节点连线 / 跨视图跳转 / "你也喜欢"型推荐 |
| **Rarity 稀有感** | 拥有别人没有的 | 光晕 / 印章 / 显著边框 |
| **Story 故事解锁** | 叙事好奇心 | 拼图揭示 / 长卷解锁 / 角色背景 |
| **Identity 身份认同** | 自我标签的强化 | 称号 / 段位 / 个性化档案 |
| **Spatial/Temporal Completion 时空完整** | 地图全开 / 时间线全亮 | 朝代柱填满 / 古国全踏足 |

避免: 单纯的"积分 + 徽章 + 排行榜" (Skinner box) — 那会让博物馆爱好者觉得我们在亵渎国宝。

---

## 1. 各维度的动机 Hook

### 1.1 时代 (时空柱)

| Hook 类型 | 具体机制 |
|----------|---------|
| **Temporal Completion** | 时空柱区段填充率,空白段微动画"呼吸",诱发"为什么我没有西周中期的?"|
| **Completion** | 子分期颗粒度 — 商早/中/晚拆出来,空白更精细更扎眼 |
| **Identity** | 段位"夏商主义者 / 周礼派 / 战国发烧友" — 根据用户收藏分布自动判定主时代 |
| **Story** | 点击某朝代区段 → 解锁该朝代的"时代故事卷" (附最重要 5-8 件器物的串联叙事) |
| **Connection** | 用户收藏的器物会在时空柱对应位置"群聚",看出自己关心的时代 |

**具体诱发场景**:
- 你打开 App 看到时空柱:
  ```
  商晚期 ████████  (16 件)
  西周早 ███       (3 件)
  西周中 ░░░       (0 件 ← 缓慢呼吸闪烁)
  西周晚 ██        (2 件)
  ```
- 心理: "为什么我没有西周中期?那是穆王恭王时代啊?" → 触发主动搜索

**判定指标**: 用户在时空柱上的平均停留 > 8 秒, 空白段点击转化率 > 15%

---

### 1.2 出土地 (古国漫游地图)

| Hook 类型 | 具体机制 |
|----------|---------|
| **Spatial Completion** | 全国遗址点 + 海外馆藏分布,空白点呼唤 |
| **Identity** | "考古足迹"称号: 走遍三大文化区 (殷墟/周原/三星堆) → "三家朝圣者" |
| **Rarity** | 三星堆/盘龙城等独立文明遗址点 = 金色,稀有标签 |
| **Story** | 每个遗址有"考古故事" — 妇好墓 1976 年发掘 / 三星堆祭祀坑 1986 发现,解锁需收藏该遗址 1 件 |
| **Connection** | 同遗址多件文物相互关联,点开一件可跳到"同坑兄弟" |

**具体诱发场景**:
- 用户已点亮 12 个中原遗址,地图右下角"三星堆"剪影孤独发亮
- 浮窗: "你还没去过 [古蜀],这里出土过 3 件国宝,与殷墟同时期"
- 心理: 异文明的吸引力被激活

**判定指标**: 古国地图月度活跃用户 > 60%, 海外馆藏点位的查看率 > 30%

---

### 1.3 馆藏地 (朝圣护照)

| Hook 类型 | 具体机制 |
|----------|---------|
| **Spatial Completion** | 9 大馆藏地印章本,集齐 = "九馆朝圣者" |
| **Identity** | 每个馆有个性化称号 — 国博常客/上博粉丝 |
| **Connection** | "去同一馆的还有 [X 件你尚未收藏的国宝]" — 触发线下行动 |
| **Story** | 海外流散篇 — 每件流散文物配一段流亡史 (如圆明园流散史),情绪驱动 |
| **Rarity** | 海外印章珍贵于国内印章 (跨洋朝圣的稀缺性) |

**具体诱发场景**:
- 用户已盖国博、河南博院 2 章,想去陕西历博却没去过
- 护照页淡灰显示陕西历博印章剪影 + "陕西历博现有你收藏的 0 件,但有 [何尊/利簋] 等 5 件待发现"
- 触发用户的下次旅行计划

**判定指标**: 护照页跳转到对应博物馆官方页的点击率 > 8%

---

### 1.4 形制 (谱系树 + 对照墙)

| Hook 类型 | 具体机制 |
|----------|---------|
| **Completion** | 同子型集齐 (如"方尊"4 件) → 解锁该子型"进化时间线"视图 |
| **Connection** | 同型号对照墙的视觉冲击 — "原来鼎有这么多变体" |
| **Identity** | "鼎类大师 / 觚的鉴定家" 类别专精称号 |
| **Story** | 集齐九鼎八簋的故事性 (天子礼制) |
| **Rarity** | 罕见形制 (如龙形觥) 单独标记 "孤型" |

**具体诱发场景**:
- 用户收藏 3 件方尊 (四羊/妇好/牺尊),对照墙显示"还差 1 件方尊解锁进化时间线"
- 第 4 个槽位剪影显示"商晚期·方尊·待补"
- 心理: 拼图心智强烈触发

**判定指标**: 对照墙浏览到 "下一件" 提示后的搜索行为 > 25%

---

### 1.5 纹路 (演化树 + 拓片本)

| Hook 类型 | 具体机制 |
|----------|---------|
| **Identity ★** | "凤鸟收藏家 / 饕餮鉴定师 / 窃曲修士" 等纹饰称号 (这是这个产品最响亮的身份感) |
| **Connection** | 拓片本可独立收藏 — 同纹饰跨器物的"纹饰家族" |
| **Story** | 纹饰演化树本身就是故事 — 神权 (饕餮) → 礼制 (窃曲) → 写实 (凤鸟) 三阶段 |
| **Completion** | 演化树分支末梢需要"该分支所有节点点亮" |
| **Rarity** | 罕见纹饰如鸱鸮纹 (商代妇好系) 单独标记 |

**具体诱发场景**:
- 用户收藏的 8 件器物里 6 件有夔龙纹 → 自动获得"夔龙派"称号
- 演化树显示: "你识别了 6/12 种夔龙变体,再识别 6 种即可升为'夔龙大宗'"
- 拓片本里整齐排着 6 张黑白拓片,用户产生收集欲

**判定指标**: 纹饰称号系统的解锁率 > 40%, 拓片本访问频次 > 3次/用户/月

---

### 1.6 用途 (场景重建)

| Hook 类型 | 具体机制 |
|----------|---------|
| **Spatial Completion** | 多套礼仪场景,缺位的器物剪影显示在场景中 |
| **Story** | 礼制故事 — 列鼎制度的等级深意,集齐天子九鼎才解锁"周礼·王道篇" |
| **Identity** | "礼器派 / 酒器派 / 乐师" 等用途专精称号 |
| **Connection** | 场景中的器物可跳转到该器物详情 — 场景是导航器 |
| **Completion** | 单场景完成度百分比,贯穿整个用户旅程 |

**具体诱发场景**:
- 用户在太牢祭祀场景已归位 7/15 件,但鬲位空缺
- 场景文案: "燕飨之礼,需鬲一件 (商-西周早) 以煮粥献神"
- 用户搜索"鬲"

**判定指标**: 场景完成度 ≥ 50% 的用户次月留存 > 70%

---

### 1.7 工艺 (工序长卷)

| Hook 类型 | 具体机制 |
|----------|---------|
| **Story ★** | 长卷本身就是工序故事,解锁感强 (一条卷子从卷起到展开) |
| **Connection** | 工艺 × 形制矩阵 — 跨维度交叉视图 |
| **Identity** | "百工之祖" (集齐 7 条长卷)/ "失蜡传人" 等称号 |
| **Completion** | 7 条长卷全开是终极目标 |
| **Rarity** | 失蜡法长卷尤其难解锁 (春秋战国少数器物才用) |

**具体诱发场景**:
- 用户解锁了范铸法长卷,但失蜡法长卷仍卷起
- 锁定提示: "解锁失蜡法,需收藏 1 件以失蜡法铸造的国宝。推荐: 曾侯乙尊盘 (湖北博物馆)"
- 用户的求知欲被精确点燃

**判定指标**: 至少解锁 3 条工序长卷的用户比例 > 25%

---

### 1.8 铭文 (释读器 + 段位)

| Hook 类型 | 具体机制 |
|----------|---------|
| **Identity ★★** | 段位制 — "金文识读·入门/一段/二段/.../鉴师/大宗师" — 这是产品最深的身份系统 |
| **Completion** | 累计识字 / 已知金文总数 (约 3700 字),长期目标 |
| **Connection** | 字字跨器关联 — "若"字出现在 7 件器,自动形成轨迹 |
| **Story** | 长铭文释读 = 解一篇文章 — 毛公鼎 499 字读完后整段故事豁然 |
| **Rarity** | 史诗铭 (300+ 字) 国宝特别标记 |

**具体诱发场景**:
- 用户识读了 187 字,段位"二段",距离三段还差 113 字
- 推荐: "大盂鼎 (291 字) 含你未识字 78 个,识读完即可冲三段"
- 用户被精准激励

**判定指标**: 重度铭文用户 (识字 >100) 月活率 > 80%, 这是产品的"忠诚用户池"

---

### 1.9 稀有度 (光晕)

| Hook 类型 | 具体机制 |
|----------|---------|
| **Rarity ★★** | 全局视觉系统,渗透所有视图 |
| **Identity** | 国宝率 = 个人收藏中禁出境/一级文物的占比,这是炫耀指标 |
| **Story** | 每件国宝有"国之重器"叙事 (为何被列入 195 件名录) |
| **Connection** | 同稀有度文物的雷达图 — "你的国宝构成" |

**具体诱发场景**:
- 用户首件国宝收藏,卡片金光乍现,旁边出现"国之重器"红章入框动画
- 全屏播放 3 秒"祝贺"动画,文案: "你的第 1 件禁出境国宝 — 这是国家不允许出门的级别"

**判定指标**: 首件国宝解锁后 7 日内分享率 > 30% (这是天然 social moment)

---

### 1.10 主人/铸造者 (铸主档案)

| Hook 类型 | 具体机制 |
|----------|---------|
| **Story ★** | 每位铸主背后的历史人物故事 |
| **Completion** | 同铸主作品收藏率 — 妇好 12 件全集是高难度长期目标 |
| **Connection** | 铸主关系图 — 把器物收藏延伸到人物收藏 |
| **Identity** | "妇好系列收藏家 / 周王作器人 / 曾侯乙乐工" |

**具体诱发场景**:
- 用户收藏了 3 件妇好系列, 档案显示 "妇好 12 件已收藏 3/12"
- 关联系统提示: "妇好的儿子祖庚也有 2 件传世器,在国博"
- 用户从"物"被引到"人",再被引到"亲属"

**判定指标**: 铸主档案的二次访问率 > 50% (说明用户开始按人组织收藏)

## 2. 反 Skinner Box 的设计纪律

明确**不做**以下:

| 不做 | 替代方案 |
|------|---------|
| ❌ 每日签到积分 | ✅ 每日"金文鉴读"挑战 (识 5 字累计积入段位) |
| ❌ 单纯排行榜 | ✅ "你的国宝率"自我对照而非比赛 |
| ❌ 普通徽章成就墙 | ✅ 维度的视觉化本身就是成就 (时空柱填满 = 成就) |
| ❌ 体力/疲劳值/广告 | ✅ 0 营销机制,纯内容驱动 |
| ❌ 抽卡机 | ✅ 必须基于真实收藏行为 (拍照识别 / 馆内确认 / 学术录入) |

**核心信念**: 博物馆爱好者反感"游戏化外壳",欢迎"游戏化内核"。差别在于,**游戏化机制是否服务于内容本身的探索**。

## 3. 维度组合 (Cross-Dimensional Synergies)

跨维度组合是高级 hook,产生 1 + 1 > 2 的动机叠加。

### 3.1 组合 A: 时代 × 出土地 — **古国时空叠加**

**结构**:
```
   ┌──────────┬─────────────────────┐
   │ 时空柱    │  古国漫游地图        │
   │ (左)      │  (右)                │
   │          │                      │
   │ 战国 ●    │   ┌─楚─┐   ┌─齐─┐   │
   │ 春秋     │   │    │   │    │   │
   │ ←──── 拖动选中"商晚期"             │
   │ 西周     │     ┌─殷墟─┐         │
   │ 商晚期 ★  │     │      │         │
   │          │   ┌─三星堆─┐         │
   │ 商中期    │   │       │          │
   │ 商早期    │                      │
   │ 夏       │   (地图自动切换到商晚期版图)│
   └──────────┴─────────────────────┘
```

**Hook 强度**:
- 商晚期 + 三星堆这种"非中原文明在同一时间存在"的事实,通过组合视图被强烈感知
- 用户从"时代视角"和"地理视角"双向切换 — 改变了对"中国"这一概念的理解
- 协同点亮的机制: 用户同时收藏了"商晚期" + "三星堆"的器物 → 解锁"二重文明见证者"称号

**动机机制**: Spatial × Temporal Completion 叠加

### 3.2 组合 B: 形制 × 用途 — **礼制完整性引擎**

**结构**:
```
   形制谱系树 ←──双向绑定──→ 用途场景重建
   ┌──────────┐               ┌──────────┐
   │ 鼎       │               │ 太牢礼   │
   │ ├ 圆鼎   │ ←─ 鼎位空缺 ─→ │ [鼎位]   │
   │ ├ 方鼎   │               │ [簋位]   │
   │ └ 扁足鼎  │               │ ...      │
   │ 簋        │               └──────────┘
   │ 觚        │
   └──────────┘

   在场景中放入新器物 → 谱系树同步点亮该子型
   在谱系树中点击空白节点 → 场景中对应位置高亮提示
```

**Hook 强度**:
- 集齐九鼎八簋 (列鼎制度) → 解锁"天子之礼"特殊视图,场景画面切换为更宏大的宗庙全景
- 双向绑定让用户感受"形制是为用途而生" — 不是机械分类,是功能服务
- 制度完整性的揭示 — 用户开始理解"为什么鼎要 9 个不是 8 个"

**动机机制**: Completion × Story 叠加,礼制感是双倍的

### 3.3 组合 C: 纹路 × 时代 — **纹饰史观**

**结构**:
```
   时空柱            纹路演化树
                              ▲
   战国 ●     ◀━━━━ 蟠虺纹 ━━┛
   春秋 ●     ◀━━━━ 窃曲纹/重环纹
   西周晚      ◀━━━━ 抽象化夔纹
   西周中      ◀━━━━ 凤鸟纹大盛
   西周早      ◀━━━━ 顾首夔纹
   商晚期 ★   ◀━━━━ 饕餮纹/夔龙纹
   商中期      ◀━━━━ 简化兽面
   商早期      ◀━━━━ 弦纹

   时空柱和演化树横轴对齐.
   选时代 → 树上对应纹饰高亮.
   选纹饰 → 时空柱该纹饰流行时代高亮.
```

**Hook 强度**:
- 用户亲眼看到"神权→礼制→抽象化"的视觉化进程
- 解锁"纹饰史学家"称号 — 收藏覆盖至少 3 个时代且每个时代都有该时代主流纹饰的用户
- 学术深度大幅提升,服务硬核用户

**动机机制**: Story × Identity 叠加

### 3.4 组合 D: 铭文 × 铸造者 — **铭文索引人**

**结构**:
```
   铭文释读中识别出"毛公"二字
            ▼
   自动跳到 铸主档案:
   ┌────────────┐
   │  毛公 (毛伯卫) │
   │  西周晚期        │
   │  现存器物:       │
   │   ● 毛公鼎 (台北故宫)│
   │   ● 毛公旅鼎      │
   │  ...             │
   └────────────┘
```

**Hook 强度**:
- 一个字打通"释字 → 找人 → 找物" 的全链路
- 用户在毛公鼎里看到的"毛公"两字,瞬间在大脑里变成立体的人物
- 这是产品里最"博士级"的功能,但每次触发都是 wow moment

**动机机制**: Connection × Identity 叠加

### 3.5 组合 E: 稀有度 × 全维度 — **全局光晕系统**

**结构**: 稀有度不是独立维度,而是**叠加在其他 9 个维度上的视觉层**:
- 时空柱里,国宝级器物的填充段会闪金光
- 古国地图上,国宝级出土点是金色徽章
- 形制谱系树里,国宝子型是金边节点
- 拓片本里,国宝铭文拓片背景泛黄古纸
- 铭文释读器里,国宝铭文有"国之重器"红章

**Hook 强度**:
- 稀有度成为产品的"血液色彩",而非分割开的标签系统
- 用户的整个收藏视图一打开就有"这个里面有多少金子"的瞬间感知
- 视觉一致性 + 稀有感 = 高级感

**动机机制**: Rarity 是全局乘数

## 4. 用户旅程层面的动机设计

### 4.1 新手 0 → 1 件 (Day 1)
- 拍照识别第一件器物 → 卡片飞入收藏夹 → 同时点亮时空柱、地图、谱系树、用途场景 多个维度的某一点
- 多维同时点亮的视觉爆发 = 强烈的 "原来一件器物有这么多面" 的认知冲击
- 称号: "踏上青铜之路"

### 4.2 早期 1 → 5 件 (Week 1)
- 5 件后,每个维度都有部分进度
- 用户开始看到自己的"收藏画像" — 是偏沉迷商代?偏好饕餮纹?喜欢国博?
- 称号: "初识三代"

### 4.3 中期 5 → 20 件 (Month 1)
- 20 件接近完成第一波时空柱和地图覆盖
- 跨维度组合开始触发: "你的鼎类已经 6 件,差 3 件解锁九鼎之礼"
- 称号: "三代见习"

### 4.4 进阶 20 → 50 件 (Month 3)
- 多个维度的进阶称号开始集齐 (饕餮鉴定师 + 鼎类大师 + 妇好系列 ...)
- 铭文段位起飞,识字数突破 100 进入"二段"
- 称号: "国宝学徒"

### 4.5 重度 50 → 200 件 (Year 1)
- 接近覆盖 195 件禁出境名录
- 铭文段位"鉴师"级,毛公鼎/史墙盘等史诗铭都已通读
- 称号: "青铜行者 / 商周朝圣者 / 三代鉴师"

每个阶段都有"维度作为障碍",但**每个障碍都是知识本身**,不是数值堆砌。

## 5. 反馈循环 (Feedback Loops)

### 5.1 短反馈 (秒级 — Hot Loop)
- 拍照识别一件 → 多维度同时点亮的视觉爆发
- 字字悬停 → 立即识别 + 段位累计 +1
- 拓片框选 → 即时拓片入收藏

### 5.2 中反馈 (分钟-小时级)
- 浏览谱系树看到自己的进度
- 切换到铸主档案看到关联人物

### 5.3 长反馈 (天-月级)
- 段位升级 (识字段位 / 朝圣段位)
- 称号解锁 (饕餮鉴定师等)
- 解锁特殊视图 (天子之礼 / 失蜡法长卷)

### 5.4 终极反馈 (年级)
- 195 件禁出境国宝全集 (这是终极目标,可能 1-2 年才达成)
- 金文识读"大宗师" (需 1000+ 字)
- 9 馆朝圣印章全集

**梯度设计原则**: 短反馈支撑日活, 中反馈支撑周活, 长反馈支撑年留存。每一层都有,缺一不可。

## 6. 给 Visualization Designer 的关键提示

1. **称号系统是隐线,不是显线** — 不要做"成就墙"页面,称号应该出现在用户头像旁的角标、分享卡片的水印里。
2. **进度可视化优先于数字** — "你点亮了商代 60%" 不如直接看时空柱填了 60%。
3. **稀有度是渗透的,不是独立的** — 不要做"国宝列表"页面 (那只是查询),要让金光在每个维度视图里闪。
4. **空白比填满更重要** — 不要急着给用户填满 — 维度视图必须**给用户看到自己的空白**,这是诱发的本源。
5. **组合视图比单视图重要** — Phase 3 的 demo 应该展示至少 1 个跨维度组合 (如时代 × 出土地)。

## 7. 评估指标 (KPIs for Motivation Layer)

| 指标 | 目标 | 测量方式 |
|------|------|---------|
| **维度页面平均停留** | > 30s | 每个维度页 (时空柱/地图等) 单独埋点 |
| **空白段点击转化** | > 15% | 空白段的悬停 → 跳转到搜索/推荐的转化 |
| **称号解锁率 (首月)** | > 60% | 月度新用户至少解锁 1 个称号 |
| **跨维度组合触发** | > 25% | 每周活跃用户中至少使用过 1 次组合视图 |
| **国宝率展示分享** | > 30% | 用户首件国宝后 7 日分享率 |
| **铭文识字累计** | 平均 > 50 字/用户 | 重度用户专属 |
| **次月留存** | > 50% | 整体激活后次月留存 |
