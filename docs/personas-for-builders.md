# Personas for Builders — 3 个 differentiated 北极星

> 这是今晚 3 个 Builder 各自的"用户画像北极星"。
> Builder 不锁视觉风格、不锁配色、不锁字体,**只锁服务的是谁**。视觉、信息密度、交互节奏,从这个人自然推导出来。
>
> 评判标准:三个 demo 拿给一个不知情的人看,30 秒内能分得清"哪版给哪类人"。
>
> 所有 persona 都属于"硬核博物馆爱好者"这一大类(`prd-demo-night.md §1`),但**核心动机不同**,因此产品形态差异巨大。

---

## A — 考据派 (Textual Researcher)

**名字**: 陈翊安。29 岁。北大考古文博学院在读博士,方向商周青铜器纹饰演变。

### 真实切片

陈翊安每周三下午是雷打不动的"国博日"。她不拍展品的全身照,只拍**展签 + 局部纹饰特写**,回来录到一份自制的 Notion 数据库里,字段有 20 多个:出处、断代依据、纹饰类型、拓本编号、参考文献页码。她书桌上常年摆着李学勤的《青铜器入门》和《殷周金文集成》第四册。她朋友圈半年没发过,但豆瓣"金文小组"她是 6 个管理员之一。

她下载过故宫、国博、湖南博物院所有 App,**全部卸载了**。原因:"信息浅,而且没有引用来源,有些断代连争议都没标"。她最近一次激动是因为发现台北故宫数位典藏放出了毛公鼎的 3D 模型,可以转角度看铭文 —— 但**还是没法做笔记**。

### 心智模型:她怎么想青铜器?

青铜器对她**不是器物,是"证据链"**。看一件鼎,她脑子里跑的是:
- 这是**哪个谱系**的鼎(柱足/兽蹄足、立耳/附耳,有没有铭文,铭文字数,字体阶段)
- 这件的**断代依据**是什么(出土层位?同墓器物群?铭文人名比对?)
- 这件在**学术史上的位置**(谁定的名,谁修订过,目前有什么争议)
- 和**馆藏地的其他同类件**关系如何(亲缘?祖孙?异地同范?)

**关键词**: 谱系、引用、争议、对照、笔记。

### 3-5 个 must-have 功能

1. **每件都有引用规范**: 来源(《集成》编号 / 报告页码 / 馆藏号)清晰标注,作者、年份、出版社齐全。能"复制 BibTeX"加分
2. **多件对比模式**: 选 2-3 件文物,字段并列摆出来对照(尺寸 / 铭文 / 纹饰构成 / 出土关系)
3. **铭文工作台**: 铭文逐字可悬停 = 字头释文 + 异体字 + 在该器中的位置
4. **形制谱系图**: 不是"鼎的列表",是"鼎"这个形制的演化树,带断代标尺
5. **个人笔记 + 导出**: 我能给每件加私有 tag、备注,导出 markdown 或 BibTeX

### 2-3 个会让她**立刻删 App** 的红线

1. **没有来源标注**: 一段描述没引用,她会假设是 GPT 编的
2. **过度游戏化**: 弹"恭喜解锁青铜大师称号"的彩带 + 音效,她会脸黑
3. **稀有度 = 星星图标**: 鉴定/分级体系不严肃化,会显得"小孩玩具"

### 她会跟同行炫耀的 killer feature

> "你看,我把毛公鼎和大盂鼎放并列,字体演变标尺把铭文的'王'字从中间 X 形演到楷化形态画出来 —— **而且每个断代点都有引用**。我没在任何 App 里见过这个。"

她会**截图发到金文小组群**。这是 portfolio 价值的体现 —— 一个能被领域内人认可的功能。

### 信息密度 & 交互范式建议

- **密度: 高,密到接近 PC 端学术工具**。一屏可以塞下 6-8 个字段,字号小但排版严谨。表格、卡片、列表混用
- **节奏: 深度优先,纵向钻取**。不要把功能藏 3 层 — 学者要的是少跳转、多信息
- **视觉: 克制、严肃、接近纸本**。建议参考:JSTOR、《文物》期刊电子版、Stanford Digital Humanities Lab。色彩低饱和,衬线字体出现在标题和铭文区,数字字段用等宽字体
- **交互锚点: 横向对照 + 跨文物链接是这版的精髓**。点一个"夔龙纹"标签,跳到所有有夔龙纹的器物列表;点一个"出于殷墟妇好墓",跳到妇好墓的同出器物组
- **游戏化的承载方式**: **隐式的"研究进度"**,不是显式的"等级"。如:你已对照过 X 对器物 / 你的笔记累计 Y 字 / 你的"纹饰图谱完成度 38%"。**完全不弹彩带**

## B — 沉浸派 (Immersive — 《国家宝藏》圈粉)

**名字**: 苏念。32 岁。杭州一家互联网公司的内容运营,中文系本科。

### 真实切片

苏念追完了《国家宝藏》全 4 季 + 《如果国宝会说话》全 3 季。她手机壁纸用过 3 个月的妇好鸮尊,现在换成长信宫灯。她最近一次哭是看到河南春晚的《唐宫夜宴》和《洛神水赋》。她的小红书有 1.2 万粉丝,主题是"普通人也能读懂的文物故事",一篇阅读量高的笔记可以做到 3 万 +。

她**真的去过湖北省博**,在曾侯乙编钟前站了 40 分钟,因为讲解员的故事让她哭了。她**没记住编钟有 65 件这种数字**,她记住的是"曾侯乙临死前会不会想象自己被这些钟送葬的样子"。

她下载过的 App **都看不下去**,原因:"全是数据,没有人在说话"。

### 心智模型:她怎么想青铜器?

青铜器对她**不是文物,是"穿越的入口"**。看一件鼎,她脑子里跑的是:
- 这件器物**当年用在什么场合**?谁碰过它?它当年发出的声音是什么样?
- 这件器物**埋藏的那一刻**,什么样的人在哭、在祭、在送别?
- 它**等了多少年才被挖出来**?最先看到它的考古队员是什么心情?
- 它如果"会说话",会说一句什么样的话?

**关键词**: 场景、时间感、人情、声音、画面。

### 3-5 个 must-have 功能

1. **首页"今日的国宝"**: 单件全屏沉浸式呈现,大字、留白、有一句作家级文案("我等了 3200 年,你来看我")
2. **场景重建**: 一件用于祭祀的鼎,把它放回**祭祀场景的氛围插画**里 —— 火光、礼乐、祭司
3. **铭文之声**: 铭文不止"释读",还有**音频朗诵**(古汉语模拟发音 + 现代汉语)。哪怕是 mock 音频,效果占位也要做出来
4. **国宝档案 - 故事线**: 每件文物有"出生 → 使用 → 埋葬 → 重见天日 → 入馆"5 段时间轴,带年代刻度,带情绪文案
5. **"我经过的国宝"时间线**: 我的收藏不是"列表",是**一卷可以滚的时光长卷**,每一件出现时有微动效 + 一两句感性 caption

### 2-3 个会让她"觉得 App 没感觉"的红线

1. **首屏是 4×4 的网格图鉴**: 像逛淘宝,不是逛博物馆
2. **大量学术术语**: "饕餮纹云雷地 C 形单角"她会跳过 —— 这版要的是"那个张着大眼的狰狞兽面"
3. **没有画面感**: 全是字 + 表格,没有插画、没有色彩、没有音

### 她会发小红书的 killer feature

> "我刚刚把后母戊鼎'放回'了商王武丁的祭祀大殿。**火光在它身上跳动,远处编钟开始响,我突然明白了为什么这个鼎要造得这么大** —— 它要的是'让神看见'。"

她会**截屏 + 8 张图发小红书**,标题"原来博物馆 App 可以这样做"。这是 K-factor 的 hook。

### 信息密度 & 交互范式建议

- **密度: 低,极度低**。一屏可能只有一件器物 + 三句话。留白是奢侈
- **节奏: 翻页式、章回式,叙事优先**。不是"找信息",是"被故事带着走"。横向滑动比纵向滚动更适合
- **视觉: 高质感、电影感、情绪化**。建议参考:NYT magazine 长篇专题、Apple "今日 App" 编辑专题页、《国家宝藏》节目片头。色彩可以用暗背景 + 高饱和点缀(青铜的青绿、金石的朱红);字体用宋体/楷书做标题,可加书法元素
- **交互锚点: 微动效是这版的精髓**。每个页面进入有 fade-in,文物图片轻微 ken-burns 缓动,翻页有"打开卷轴"的暗喻
- **游戏化的承载方式**: **情感性的"足迹收集"**,不是分数。如"你已经走过 7 件国宝,听过它们的 7 段往事";"长信宫灯还在等你点亮";一段"国宝独白"作为解锁奖励。**收藏的反馈是诗意的,不是 +1 的**

## C — 探索派 (Explorer — Z 世代游戏厅心态)

**名字**: 阿 K(真名李珂,但同好都叫她阿 K)。21 岁。上海某美院视觉传达大三在读。

### 真实切片

阿 K 是那种**会用周末打卡 3 个博物馆**的人 —— 不是因为爱好,而是因为"有趣"。她玩崩坏星穹铁道全角色满级,追《原神》璃月剧情线时去翻了一堆中国神话,然后顺手买了博物馆年卡。她的小红书内容是"博物馆探店 vlog 风",标题常是"震惊!这个鼎居然是 3000 年前的'胖虎'"。她有 8000 粉,**主力变现是带朋友刷博物馆周边、做 cosplay 道具参考**。

她下载博物馆 App 的频率最高,**用一次就卸**。原因:"无聊。我有那时间不如玩游戏"。但她对**集换卡牌、解锁动画、稀有度光效**毫无抵抗力。Pokemon GO 当年她日活 300 天。

### 心智模型:她怎么想青铜器?

青铜器对她**不是文物,是"PVE 副本里的稀有掉落"**。看一件鼎,她脑子里跑的是:
- 这个鼎是**几星稀有度**?能不能闪一下?
- 我朋友收过吗?**我有他没有的吗**?(社交位差)
- 这玩意儿**能不能 P 进我的手帐 / cos 道具**里?
- 它的**梗在哪**?有什么有趣的反差?(后母戊鼎=最重的网红?长信宫灯=最早的环保设计?)

**关键词**: 稀有度、收集、社交、梗、视觉冲击。

### 3-5 个 must-have 功能

1. **抽卡式入口**: 首页有一个"今日推荐国宝"用**抽卡动效**呈现 —— 卡背翻转 → 光晕 → 卡正面文物大图 + 稀有度评级
2. **稀有度可视化炸裂**: 国宝级有**金色光晕 + 粒子**,出土地稀有(三星堆 / 海昏侯)有专属特效。点开看详情前就能"嘶"一声
3. **图鉴完成度仪表盘**: 大块数字 + 进度条 + 章节名("商代收藏 12/15")。可以**截图发朋友圈**就是这版的核心 KPI
4. **梗卡片化分享**: 每件文物可以一键生成"梗卡片"(模板化海报),带 caption 模板("我比国博还早收藏到 XX 鼎"),一键分享微信/小红书
5. **彩蛋/隐藏成就**: 集齐 3 个三星堆 → 解锁"古蜀勘探者"称号 + 隐藏皮肤;在同一天打开 App 5 次 → 解锁"日活国宝"成就 —— 这种**游戏圈味道**的成就体系

### 2-3 个会让她"3 分钟卸载"的红线

1. **进入就是文字 + 介绍**: 没有"打开有惊喜"的钩子,直接劝退
2. **稀有度没有视觉差异**: 国宝跟二级文物看起来一样,她会觉得"那我集这玩意儿干嘛"
3. **分享卡片丑**: 朋友圈晒了被嘲"小学生作业",直接卸

### 她会发抖音的 killer feature

> "我刷到一个 App,点进去**居然给我抽卡**,我抽中了三星堆青铜大立人 —— **金光闪闪那种,跟原神五星抽卡一样的特效**。然后它告诉我'你是第 17 个收到这个的'。OK,**我已经下载到地铁上抽**了。"

她会**录抖音**。这是病毒传播 hook。

### 信息密度 & 交互范式建议

- **密度: 极低,但视觉密度极高**。一屏少字,但满屏发光发亮的视觉元素
- **节奏: 短平快,3 秒 + 7 秒**。3 秒抓住眼球(动效/特效),7 秒理解功能。深度内容**藏在二级页**,但首屏必须爽
- **视觉: 高饱和、有粒子、像游戏 UI**。建议参考:原神 / 崩坏星穹铁道的角色界面、Pokemon GO 收图鉴页、网易蛋仔 / 旅行青蛙的卡片系统。可以大胆用霓虹色、毛玻璃、3D 卡片翻转
- **交互锚点: 触觉化的动效是这版的精髓**。每个点击有反馈震动(视觉模拟震动),每个收藏有掉落动画,每个解锁有 fanfare 效果。**别怕 over**
- **游戏化的承载方式**: **显式 + 表演性**。等级、徽章、进度条、抽卡、皮肤、社交对比 —— **全开**。这版正是把游戏化拉到天花板,作为审美极端样本。**它会和 A 版形成最强烈对比,这是 Comparative Auditor 最关心的素材**

## 三版张力总结(给 Comparative Auditor 提前预热)

| 维度 | A 考据派 | B 沉浸派 | C 探索派 |
|------|---------|---------|---------|
| **核心动机** | 知识累积 / 学术对照 | 情感共鸣 / 故事代入 | 收集快感 / 社交炫耀 |
| **目标人群** | 5% 的硬核 | 70% 的泛文化爱好者 | 25% 的 Z 世代/破圈 |
| **信息密度** | 极高 | 极低 | 低(但视觉密度高) |
| **首屏第一秒看到** | 索引 / 工具栏 | 一件国宝 + 一句诗 | 抽卡动画 / 闪光卡片 |
| **游戏化形态** | 隐式 / 笔记进度 | 情感性 / 足迹长卷 | 显式 / 抽卡 + 稀有度炸裂 |
| **杀手 feature** | 多件对照 + 引用 + 谱系 | 场景重建 + 国宝独白 | 抽卡 + 稀有度光晕 + 梗卡片 |
| **不可逾越的红线** | 不严肃 / 无引用 | 没画面感 / 太多术语 | 没有"开盲盒"惊喜 |

**真正的产品决策不是"选一版",而是要在 C1 review 后想清楚:**

> "可不可以让一个 App 同时承载 A 的严肃 + B 的故事 + C 的成瘾,通过不同入口 / 不同模式 / 不同信息层折叠出来?"

这就是 Comparative Auditor 要在 `merged-spec.md` 里回答的问题。
