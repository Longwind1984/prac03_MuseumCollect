# Gamification Mechanics — 系统级游戏化机制

> Visualization Designer · Phase 2 of Night Run D0
> 配套: 10 个 component-specs/*.md
>
> 这不是"积分 + 徽章 + 排行榜"的清单。这是一份**游戏化系统设计文档**,
> 论点是: **维度本身 = 动机,组件本身 = 进度,收藏本身 = 段位**。
> 我们要做的不是"在博物馆里贴游戏机制",而是"让博物馆爱好者的认知自我加速"。

---

## 0. 论点(三句话)

1. **形态 = 进度条**:时空柱本身就是收藏进度,古国地图本身就是漫游成就,演化树本身就是鉴别等级。不另搞一套积分。
2. **空白 > 填满**:维度组件的核心信息不是"用户已收藏什么",是"用户还没看见什么"。空白段、虚线节点、剪影位置是产品的引力源。
3. **认知能力 = 奖励**:用户得到的不是"+1000 XP",是"你现在能区分饕餮和窃曲了""你看出了这件鼎和那件鼎的家族关系"。这种自我能力的提升是博物馆爱好者的真实回报。

---

## 1. 用户旅程:Day 1 / Week 1 / Month 1 / Year 1

### 1.1 Day 1 — 第一次打开

**第一次 wow moment**: 用户拍照 / 选中 / 浏览到第一件器物(假设是后母戊鼎),**多个维度同时点亮的视觉爆发**:
- 时空柱: 商晚期段从 0 跳到 1 件,该段瞬间从呼吸状态切到铜绿填充
- 古国地图: 殷墟点位从虚线圆圈变成"鼎剪影 + 朱砂星标"
- 形制谱系: 鼎 > 方鼎 节点点亮,对照墙加一件
- 纹饰演化: 饕餮纹 + 夔龙纹 + 云雷纹 三个节点同时点亮(因为后母戊鼎有这三种纹)
- 用途场景: 太牢礼祭祀场景的"主鼎位"亮起一格
- 稀有度: 卡片金光 + "国之重器"红章入框 + 全屏 3 秒祝贺动画

**心理冲击**: 用户原本以为是"我把一件东西放进收藏夹",结果是**"一件器物在 6 个维度里同时改写了我的认知地图"**。
**称号**: "踏上青铜之路" — 这是唯一一个对所有用户保证 Day 1 解锁的称号

**让他回来明天的钩**:
- 多维同时点亮后,某个维度的"邻近空白"会自动浮出小提示。比如时空柱"商晚期"亮起后,旁边的"商中期"段落开始呼吸,文案"商中期(盘庚迁殷前)你尚未踏足,妇好之前还有 200 年的商王朝"
- 不发推送通知;不做每日签到 — 让用户**因为求知欲回来**,不是因为系统提醒

---

### 1.2 Week 1 — 第 5-10 件

**Session goal**(用户每次打开 App 想达成的隐性目标):
- "把时空柱的某个朝代段填到 50%"
- "去三星堆点亮"
- "解锁第一条工艺长卷"
- 看自己的收藏画像:是偏沉迷商代?偏好饕餮纹?喜欢国博?

**"几乎到了"的钩**:
- 形制对照墙: "方尊集 3/4,还差 1 件解锁进化时间线" — 第 4 件方尊的剪影在那里诱发
- 工艺长卷: 卷起的失蜡法长卷右下角小字 "再 1 件失蜡法器物,可展开" — 卷轴透视感本身就是诱
- 铭文段位: 累计 47 字,距下一段位还差 3 字 — 这种"几乎够到"的诱发力是最强的

**称号**: "初识三代" / "饕餮派(初阶)" / "国博常客"

**反 Skinner box 的关键约束**:
- 不在用户没有持续动机时主动推送
- 不做"7 日连续打开领取奖励"
- 称号是产生的副产品,不是目标
- 如果用户停留 3 天没打开,**什么都不做** — 这是正确的产品节制

---

### 1.3 Month 1 — 第 20-30 件

**Session goal**: 跨维度组合开始触发,用户进入"系统思考"模式
- "你的鼎类已经 6 件,差 3 件解锁九鼎之礼"(组合 B 触发)
- "你已识 187 字,距三段还差 113 字"(铭文段位推进)
- "你已踏足 3 个文化区(中原/古蜀/楚),还有 2 个待开:吴越/燕赵"(地图深度)

**mastery 的开端**: 用户开始能**主动选择**下一件要收藏的器物,不是被推荐 — 这是"鉴赏力" 的萌芽。比如用户为了完成方尊集齐,主动搜"还有哪 1 件方尊"。

**称号(累积)**: "三代见习" + "饕餮鉴定师" + "国博常客" + "铭文识读·二段" — 多个称号叠加在头像旁

**特殊视图解锁**:
- 集齐方尊 4 件 → 解锁"方尊进化时间线"特殊视图
- 集齐妇好系 5 件 → 解锁"妇好祭祀场景"
- 解锁 3 条工艺长卷 → 解锁"工艺 × 形制矩阵"视图

---

### 1.4 Month 3 — 第 50 件

**mastery 的真实呈现**:
- 铭文段位"三段"(150+ 字)— 用户已能独立认出大半常见金文
- 多个维度的进阶称号集齐(饕餮鉴定师 + 鼎类大师 + 妇好系列 + 西周通鉴)
- 在路上看到一件没见过的青铜器,**用户能主动猜断代和形制**

**这是产品的转折点**: 从"用 App"变成"用脑"。从"收藏数字"变成"鉴赏能力"。
**称号**: "国宝学徒" / "金文识读·三段" / "六国漫游者"

---

### 1.5 Year 1 — 第 100-200 件

**Identity / status**:
- 接近覆盖 195 件禁出境名录的 50% — 这是国际级博物馆爱好者的水平
- 铭文段位"鉴师"级,毛公鼎/史墙盘等史诗铭通读
- 多个跨维度组合视图全开
- 用户在朋友圈被认作"那个懂青铜器的人"

**称号**: "青铜行者 / 商周朝圣者 / 三代鉴师" / "金文识读·鉴师"

**终极反馈**: 不是 App 内的"通关动画",是用户在真实生活中的认知地位 — 同事问他"这是个什么鼎",他能答上来,**这才是产品的最终回报**。

## 2. 跨组件协同(产品差异化的真正杀手)

5 个跨维度组合(继承自 motivation-hooks §3),从游戏机制角度细化:

### 2.1 组合 A: 时代 × 出土地 — "古国时空叠加"

**机制**:
- 时空柱左侧 + 古国地图右侧分屏 — 任一组件操作,另一组件同步
- 时空柱点击"商晚期" → 地图自动切到商版图,殷墟和三星堆同时点亮(并列存在的两个文明)
- 地图切到"商代版图" → 时空柱"商"段自动突出

**解锁机制**:
- 用户在该时代里 + 该古国里都收藏了至少 1 件器物 → 获得"二重见证者"称号(如"商晚期·中原 + 古蜀 二重文明见证者")
- 集齐 3 个跨时代-跨地理的搭配 → "时空漫游者"

**为什么重要**: 中原中心论的破除 — 三星堆与殷墟同时存在的事实,通过这个组合视图被强烈感知。这改变了用户对"中国"概念的理解。

### 2.2 组合 B: 形制 × 用途 — "礼制完整性引擎"

**机制**:
- 形制谱系树和场景重建场景**双向绑定**
- 用户在场景中放入一件方鼎 → 谱系树同步点亮该子型
- 在谱系树中点击空白节点 → 场景中对应位置高亮提示

**解锁机制**:
- 集齐九鼎(在场景中归位)+ 八簋 → 解锁"天子之礼"特殊视图,场景画面切换为宏大宗庙全景
- 集齐五鼎 → "诸侯之礼"
- 集齐三鼎 → "大夫之礼"

**为什么重要**: 用户开始**用身体记得**列鼎制度 — "为什么鼎是 9 个不是 8 个"不再是知识,是"我把第 9 个鼎放进格子时画面发生了什么"的经历。

### 2.3 组合 C: 纹路 × 时代 — "纹饰史观"

**机制**:
- 时空柱垂直轴 + 纹饰演化树横向轴 — 共享时代坐标
- 滚动时空柱到"西周中期" → 纹饰演化树"凤鸟纹"分支自动高亮
- 点击演化树"窃曲纹" → 时空柱"西周晚期"高亮

**解锁机制**:
- 用户收藏覆盖至少 3 个时代,且每个时代都有该时代主流纹饰的器物 → 获得"纹饰史学家"称号
- 看完"神权(商)→ 礼制(西周)→ 抽象化(春秋)"完整演化 → 解锁"纹饰史观"叙事卷

**为什么重要**: 学术深度大幅提升,这是 A 考据派最被打动的组合;同时对 B 沉浸派也有视觉冲击("一根线条三千年的演变")。

### 2.4 组合 D: 铭文 × 铸造者 — "铭文索引人"

**机制**:
- 铭文释读器中识到"毛公"二字 → 自动跳铸主档案卡(毛公)
- 铸主档案卡的"关联国宝"列表点击器物 → 跳器物详情 → 详情页铭文释读 → 这是个三角循环

**解锁机制**:
- 用户在铭文中识到至少 5 位铸主名字 → 解锁"铭文索引人"称号
- 集齐妇好 + 武丁 + 妇妌 三位殷王武丁家族成员的器物 → 解锁"殷王武丁家族"专属档案集

**为什么重要**: 一个字打通"释字 → 找人 → 找物"全链路。这是产品**博士级 wow moment**的来源 — 用户在毛公鼎里看到的"毛公"两字,瞬间在脑里变成立体的人物。

### 2.5 组合 E: 稀有度 × 全维度 — "全局光晕系统"

**机制**: 稀有度不是独立维度,是**叠加在其他 9 个维度上的视觉层**。详细见 `rarity-halo.md`。

**解锁机制**:
- 首件国宝解锁 → 3 秒克制祝贺动画 + 分享按钮 → 7 日内的天然分享率应 > 30%
- "国宝率" 是个人收藏含金量指标 — 你的国宝率 14% vs 行业平均 4% — 这是无需排行榜的自我对照

**为什么重要**: 稀有感植根于"国之重器"传统视觉语言,而非游戏化星星。这是博物馆爱好者的硬核分界线。

## 3. 反 Skinner box 的设计纪律(明确不做的清单)

### 不做(及替代)

| 不做 | 替代 |
|------|------|
| ❌ 每日签到积分 | ✅ 每日"金文鉴读"挑战(识 5 字累入段位,完全可选) |
| ❌ 体力 / 疲劳值 / 等待 | ✅ 收藏速度无限制,但收藏行为本身需要"线下凭证"(扫描/确认见过) |
| ❌ 单纯排行榜 | ✅ "你的国宝率"自我对照而非比赛(C 探索派允许本地朋友对比) |
| ❌ 普通徽章成就墙 | ✅ 维度的视觉化本身就是成就 — 时空柱填满 = 商代通鉴 |
| ❌ 抽卡机 / 概率掉落 | ✅ 必须基于真实收藏(拍照识别 / 馆内确认 / 学术录入) |
| ❌ 限时活动 / FOMO | ✅ 0 营销机制,纯内容驱动 |
| ❌ 推送通知 | ✅ 用户因求知回来,不是因系统提醒 |
| ❌ 充值解锁 | ✅ 全免费(商业化是 v2 议题,核心机制不涉及付费墙) |
| ❌ XP 数值面板 | ✅ 段位制(篆刻印章,围棋传统) |

### "游戏化外壳 vs 游戏化内核" 的分界

**博物馆爱好者反感"游戏化外壳",欢迎"游戏化内核"**:
- 外壳 = 把内容硬贴星级 / 徽章 / 排行榜
- 内核 = 让游戏机制服务于内容本身的探索

我们做内核,不做外壳。

## 4. 反馈循环梯度

| 反馈层 | 时间尺度 | 例子 | 服务的留存目标 |
|--------|---------|------|---------------|
| **Hot Loop** | 秒级 | 拍照识别 → 多维同时点亮 | day-1 hook |
| **Short Loop** | 分钟级 | 字字悬停 → 识字 +1 / 拓片框选 → 即时入册 | 单次会话内的微正反馈 |
| **Mid Loop** | 小时级 | 浏览谱系树看到进度 / 切到铸主档案看关联 | 单次会话长度 |
| **Day Loop** | 日级 | 段位累计 / 一周内新发现 X 件 | weekly engagement |
| **Long Loop** | 周-月级 | 称号解锁(饕餮鉴定师等)/ 特殊视图解锁(进化时间线/天子之礼) | monthly retention |
| **Year Loop** | 年级 | 195 件禁出境全集 / 大宗师段位 / 9 馆朝圣印章 | year-1 identity |

**梯度设计原则**:**每一层都有反馈,缺一不可**。短反馈支撑日活,中反馈支撑周活,长反馈支撑年留存。

## 5. 失败模式与 off-ramp 设计

### 5.1 收 5 件就停了的用户

**情境**: 用户拍照识别了 5 件,2 周没打开了。这是大概率发生的场景。

**off-ramp 设计**:
- **不发推送通知**(不做留存挽回)
- **App 内静态保留** — 用户的 5 件依然在,时空柱依然显示他的进度,他什么时候回来都能看到自己留下的痕迹
- **空白段不"恶化"** — 不要因为用户离开就让空白段变红 / 加紧迫感
- **重新打开时,不显示"欢迎回来,你已离开 N 天"** — 像古书,不会嫌弃读者读得慢

**核心信念**: 收藏 5 件就走的用户不是失败用户,是"暂时不需要" 的用户。我们的任务不是抓住他,是不让他对这个产品反感 — 让他回博物馆时想起这个 App,而不是想起这个 App 在催他。

### 5.2 收 100 件后开始"集齐疲劳"的用户

**情境**: 用户已收藏 100+ 件,部分维度满了,部分维度的"剩下的几件"在偏远馆藏(海外/台北),线下达不到。

**off-ramp 设计**:
- **不强求"100% 完成"** — 不在 me 页突出"完成度 87%"这种数字
- 引导用户**横向拓展**: "你商代鼎已多,推荐你试试西周早期的食器" 或 "你已掌握范铸法,试试错金银工艺"
- 解锁"研究者模式"(给 A 考据派) — 用户可以**给器物加私人笔记 / 写论文 / 导出研究材料**,App 从"收藏"升级到"工具"

### 5.3 "为了称号而收藏" 的异化

**情境**: 用户为了凑齐"妇好 12 件" 而对妇好系列疲劳。

**off-ramp**:
- 称号系统是隐线 — 不在 UI 主位显示"还差 X 件解锁"
- 称号解锁也不弹大量奖励,只是头像旁悄悄加一枚小印章
- 如果用户连续 7 天只追同一个称号 → **不做任何引导** — 让用户自己感觉"这样收藏挺无聊的"
- 永远不在 UI 上有"还有 3 件就达成"的红字 / 紧迫感

## 6. 称号系统总览(隐线非显线)

**核心原则**: 称号是产生的副产品,不是目标。

### 称号分类(约 30 个,服务不同用户切面)

**维度类称号**:
- 朝代: 夏商主义者 / 周礼派 / 战国发烧友 / 秦汉粉
- 形制: 鼎类大师 / 觚的鉴定家 / 尊神 / 簋之友
- 纹饰: 饕餮鉴定师 / 凤鸟收藏家 / 窃曲修士 / 夔龙派
- 工艺: 范铸传人 / 失蜡传人 / 错金能手 / 百工之祖(集 6 工艺)
- 用途: 礼器派 / 酒器派 / 乐师 / 兵家

**段位类称号(铭文专属)**:
- 入门 → 一段 → 二段 → 三段 → 鉴师 → 大宗师

**朝圣类称号**:
- 国博常客 / 三家朝圣者(殷墟 + 盘龙城 + 三星堆) / 九馆朝圣者

**跨维度类称号**:
- 二重文明见证者 / 纹饰史学家 / 铭文索引人 / 时空漫游者

**铸主类称号**:
- 妇好系列收藏家 / 周王作器人 / 曾侯乙乐工

**稀有度类称号**:
- 国宝学徒(10 件国宝)/ 国宝收藏家(50 件)/ 国宝学者(100 件)

### 称号呈现方式

- **称号挂在用户头像旁的角标**(最多显示 3 个,优先级:段位 > 跨维度 > 维度专精)
- **分享卡片水印** — 用户分享时称号自动印在卡片角落
- **不做"成就墙"专页** — 不让用户专门去看"我有多少成就"
- **不弹彩带/不响音/不全屏遮挡** — 解锁时只是头像旁悄悄加印章

## 7. 各 persona 的游戏化方差

| 维度 | A 考据派 | B 沉浸派 | C 探索派 |
|------|---------|---------|---------|
| **游戏化可见度** | 隐到几乎不见 | 中等(情感性) | 全开(显式) |
| **称号呈现** | 灰色小字 + BibTeX 风格 | 古典印章 + 一句诗 | 闪光卡 + 抖音体 |
| **段位升级动画** | 一行系统消息 | 山水卷轴展开 + 古琴音 | fanfare 彩带 + 粒子(可关) |
| **空白填充诱发** | "未完成的研究" 语义 | "未踏足的故事" 语义 | "还没集齐的图鉴" 语义 |
| **首件国宝解锁** | 朱砂红章+一行文字 | 3 秒电影感动画 | 抽卡式 3D 翻面 |
| **分享卡片** | 学术风(无装饰,字段密) | 文学风(一句诗+一张图) | 网红风(梗+稀有度+对比) |
| **称号词典** | 学术(纹饰收藏家)| 诗意(夔龙信徒)| 网感(青铜见习生)|

但**底层机制一致**:维度本身是进度,空白本身是诱发,认知能力是奖励。

## 8. 关键 KPI(motivation 层)

| 指标 | 目标 | 测量 |
|------|------|------|

## 9. 关键论点重申(给 Auditor / Builder / PM 都看)

1. **形态承载意义,不装饰意义** — 时空柱不是装饰的时间线,是身体能感觉到的时间厚度
2. **空白比填满更重要** — 给用户看到自己的空白,是诱发的本源
3. **稀有度是渗透的,不是独立的** — 不做国宝列表页,要让金光在每个组件视图里闪
4. **称号是隐线,不是显线** — 不做成就墙;称号出现在头像角标和分享卡水印
5. **进度可视化优先于数字** — "商代 60%" 不如直接看时空柱填了 60%
6. **组合视图比单视图重要** — Phase 3 demo 必有至少 1 个跨维度组合实现
7. **认知能力 = 真实奖励** — 用户得到的是鉴别力的提升,不是 XP
