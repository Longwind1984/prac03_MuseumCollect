# Time-Pillar — 时代维度 (时空柱)

## One-line purpose
把"时代"做成一根**身体能感觉到时间厚度**的垂直柱,用户在它上面看到的不是 timeline 装饰,而是"我的青铜认知在历史里覆盖了哪些段落、还有哪些是空白"。

## Visual description

一根**贯穿屏幕高度**的垂直柱,从下到上是夏→商→西周→春秋→战国→秦汉。每一段的**高度严格正比于该朝代时长**(商 554 年,西周 275 年,夏 250 年),不是等分。每段内部进一步切分子分期(商早/中/晚,西周早/中/晚)。

每段的**填充率 = 已收藏件数 / 该期 mock 数据池件数**(百分比,不是绝对数,以保护"夏"这种小朝代的存在感)。已收藏部分用**铜绿叠青铜暗金**的渐变填充,未收藏部分是**做旧素纸**底色。

**关键视觉细节**:
- 朝代段之间的横线**不是均分**,是真实历史断点(武王伐纣 / 平王东迁 / 三家分晋 / 秦统一)
- 子分期是嵌套的,默认折叠,点击展开
- 已收藏件以**微缩缩略图**沉浮在对应段落内,密度即热度
- 完全空白段有**呼吸式微动画**(opacity 0.4↔0.8,8 秒循环),空越久呼吸越强

## Interaction behavior

- **默认状态**: 柱体居中,自动按"商晚期"位置滚动到屏幕中央(用户收藏最集中的段落)
- **Hover 朝代段**: 该段微微"放大"(scale 1.03)+ 右侧浮出该期摘要(年代、件数、代表器 3 个)
- **Click 朝代段**: 该段展开为子分期视图;再点击子分期 → 跳出该期收藏的件物 grid
- **Drag 上下滑动**: 柱体在视口内平移(像翻卷轴),不放大缩小
- **Pinch / 滚轮 zoom**: 进入"细化视图",每段子分期都进一步显示重大事件年(穆王/恭王/孝王...)
- **Long-press 空白段**: 弹出"召唤" tooltip — "西周中期 (穆王恭王懿孝王 100 年),你尚未踏足;以下 3 件代表器在等你:[利簋·...·...]" → 点击跳转到 catalog 的对应筛选
- **Transitions**: 段落填充用 `cubic-bezier(0.4, 0, 0.2, 1)` 200ms 缓动;新收藏入段时,缩略图从屏幕外飞入,落在段内的真实年代位置

## Data requirements

**Required fields from `bronze-treasures-v1.json`**:
- `dynasty`(夏/商/西周/春秋/战国/秦/汉)
- `period`(子分期:商代晚期、西周早期...)
- `approx_year`(用于在段内精确定位件物落点)
- `name_zh`、`id`(用于缩略图标注与跳转)
- `rarity_level`(用于段内件物是否带金光晕,见 rarity-halo.md)

**Derived data (compute from records)**:
- `dynasty_pool[d]` = 该朝代 mock 数据池总件数(分母)
- `dynasty_collected[d]` = 用户已收藏件数(分子)
- `period_height_ratio[d]` = 该朝代年数 / 总年数(从 -1750 到 220,约 1970 年)
- `cold_period_score[d]` = 距上次收藏的天数 + 已知件数 - 已收藏件数,用于呼吸强度排序(分越高呼吸越亮)

**User state needed**: `user.collected_ids[]`、`user.collected_dates{id: date}`(用于"最新入柱动画")

## Game mechanic hook

- **空白即诱发**: 商早期/中期完全空白 → 大段持续呼吸,用户每次打开 app 都会被这片"空"看一眼,产生"为什么我对商早期一无所知"的羞耻
- **填充满即解锁**: 任一朝代填充 ≥ 80% → 段头出现"通鉴"印章(西周通鉴/商通鉴),并解锁该朝代的"时代故事卷"(本身指向 craft-scroll 或 caster-profile 的特殊视图)
- **"几乎到了"提示**: 填充 ≥ 60% 的段落,段尾自动浮出"再 X 件解锁 [朝代名] 通鉴"小字,无弹窗,只是诱
- **完全空 ≠ 0**: 完全空白段不显示"0/12",而是显示"待踏足"的灰色刻字,语义比数字更深

## Implementation hint

- **Tech**: SVG + 少量 framer-motion(柱体段落是 SVG `<rect>` + clipPath 填充,缩略图绝对定位)
- **Approximate complexity**: moderate(SVG 高度按比例换算 + 段内布局)
- **Libraries**: D3.js 用于按比例切割段高度,framer-motion 做呼吸动画。Tailwind 用于面板配色
- **Mobile considerations**: 柱体宽度自适应(桌面 480px,移动 280px),子分期默认折叠,Long-press 改为 tap-and-hold 300ms,zoom 用 pinch

## Cross-component connection

1. **时代 × 出土地(组合 A)**: 与 `ancient-map.md` 横向联动 — 点击某朝代段 → 古国地图自动切到该时代版图(殷墟亮 / 周原黯)。详 motivation-hooks.md §3.1。
2. **纹路 × 时代(组合 C)**: 与 `pattern-tree.md` 横轴对齐 — 滚动柱体到"西周中期"时,纹路树上"凤鸟纹"分支自动高亮。详 motivation-hooks.md §3.3。
3. **稀有度光晕**: 国宝级收藏件落在柱内时,周围有金色微光晕(见 `rarity-halo.md`),柱体填充段中国宝占比可在段头显示金圈百分比

## Persona differentiation

- **A 考据派**: 柱体右侧出现"考古事件"小字注(妇好墓发现 1976 / 何尊定名 1975 / 牧野之战公元前 1046),每个标注可点开看引用来源;子分期默认全展开;段内件物以"目录条目"形式显示而非缩略图,字号小但携带断代依据
- **B 沉浸派**: 柱体填色不是平铺,是**渐变云气纹**;段落切换有"翻卷轴"音效占位;hover 段时浮出一句作家级文案"商,贞人的时代;周,礼乐的时代";空白段呼吸更慢更哀伤,像一段没人讲的故事
- **C 探索派**: 柱体顶部固定显示"通鉴解锁进度 3/6 朝代";收藏满 80% 的段头有金色"通鉴" 印章 + 缩放放大动效;每件新入柱有"叮"的视觉粒子从底部飞起;朝代段可整段截图,自动生成"我已征服商代" 分享卡片

## Don't do these

1. **不要把朝代画成等长方格**(默认 timeline 模式的最大错误)— 时长真实感是这个组件的灵魂
2. **不要在柱体上加 XP 进度条或星星**— 时代不是关卡,稀有度光晕已经在做这件事
3. **不要把空白段做成"待开放"灰锁**— 这会让用户觉得是付费墙;空白段是诱发,不是禁止,文案应该是"待踏足"而不是"未解锁"
