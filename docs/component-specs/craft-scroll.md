# Craft-Scroll — 工艺维度 (工序长卷)

## One-line purpose
把"工艺"这种 invisible knowledge 翻译成**横向展开的国画分镜长卷** — 用户每收藏一件特定工艺的器物,该工艺的长卷"展开"一次,从卷起到全开是用户从外行到内行的可视化进阶。

## Visual description

每种工艺一条**独立的横向长卷**,共 6 条,默认全部"卷起来"(只露出标题段),解锁后"展开":

1. **范铸法长卷**(主流,商周通用,容易解锁)
2. **失蜡法长卷**(春秋战国出现,曾侯乙尊盘代表,难解锁)
3. **错金银长卷**(战国-汉,长信宫灯代表)
4. **镶嵌绿松石长卷**(二里头始)
5. **鎏金长卷**(汉)
6. **分铸/焊接长卷**(商晚-周,四羊方尊代表)

每条长卷由 6-10 个**国画分镜格**组成,每格描绘一道工序,带毛笔题字:
- 范铸法: ①制泥模 → ②翻外范 → ③制内范 → ④合范留浇道 → ⑤熔铜(1200℃) → ⑥浇铸 → ⑦冷却脱范 → ⑧打磨修整
- 失蜡法: ①制蜡模 → ②外裹耐火泥 → ③加热融蜡(失蜡) → ④浇铸 → ⑤敲掉外泥 → ⑥成品

**关键视觉细节**:
- 卷轴的"卷起"状态: SVG 用 perspective 透视效果模拟卷起,首尾用毛笔速写的卷轴杆
- 展开过程: 卷轴从右向左缓缓展开(用户点击 "展开" 时,带 1.2s 的动画)
- 工序格的画面: 国画线描 + 淡彩(青绿、赭石、藤黄、朱砂),不要照片
- 每格底部毛笔题字,字体用楷书或行楷
- 已解锁的长卷整体偏暖色,未解锁的偏冷灰

## Interaction behavior

- **默认状态**: 6 条长卷面板,显示哪些已解锁、哪些卷起
- **Click 已解锁长卷**: 整屏切换为该长卷展开视图,左右滚动浏览
- **Click 未解锁长卷**: 弹出 "解锁条件" 卡片 — "需收藏 1 件失蜡法器物。推荐: 曾侯乙尊盘(湖北博物馆)" + 跳转按钮
- **Hover 长卷分镜格**: 该格放大 + 浮出工序说明详文("熔铜需 1200℃,商周用木炭和皮鼓风,要求工匠精确判断颜色")
- **Click 分镜格**: 浮窗放大,显示该工序的考古证据(出土过的范、模、坩埚的照片或线描)
- **滑动 / 滚轮**: 横向浏览长卷,带惯性
- **Transitions**: 卷轴展开 1.2s `cubic-bezier(0.4, 0, 0.2, 1)`;首次解锁有"卷轴坠地、缓缓展开"的特殊动画 3 秒,可跳过

## Data requirements

**Required fields from `bronze-treasures-v1.json`**:
- `craft`(工艺,需要解析:"范铸法" / "失蜡法" / "范铸法 + 分铸"等)
- `id`、`name_zh`、`current_museum`(用于推荐)
- `rarity_level`(用于推荐排序)

**Derived data**:
- `craft_definitions[]` — 6 条工艺的分镜数据(每条 6-10 格,每格的标题、解释、画图占位)
- `craft_unlocked{craft: bool}` — 用户是否解锁某工艺(=用户收藏过至少 1 件该工艺器物)
- `craft_coverage{craft: count}` — 用户在该工艺下收藏了多少件
- 推荐器物的辅助 mapping: `craft_recommendations{craft: [unique_recommended_ids]}`

**User state**: `user.collected_ids[]`,`user.unlocked_crafts[]`,`user.craft_titles[]`(已解锁称号)

## Game mechanic hook

- **Story hook ★(主)**: 长卷本身就是一个"知识解锁"的故事 — 从卷起到全开,是用户认知的从无到有。这种从"看不见"到"看见"的揭示感,是博物馆 App 应该追求的核心快感
- **稀缺工艺**: 失蜡法长卷尤其难解锁(春秋战国少数器物才用),解锁那刻满足感极强
- **称号体系**: 解锁全部 6 条长卷 → "百工之祖" 终极称号;单条解锁"范铸传人 / 失蜡传人"
- **跨维度矩阵**: 高级视图 — 工艺 × 形制矩阵(横轴形制,纵轴工艺,格子里是用户的件物)。直观看出 "我有 3 件范铸鼎,0 件失蜡尊"
- **教育性钩子**: 每解锁一条长卷,用户对所有该工艺的器物理解都升一档 — 这是产品给用户的真实知识回报

## Implementation hint

- **Tech**: HTML + CSS3D(卷轴 perspective + rotateY)+ SVG 分镜画(由 Builder B 的能力定生死,需要画插画 — 沉浸派最适合做)+ framer-motion 做展开动画
- **Approximate complexity**: hard(主要在画分镜插画上,工程实现不难)
- **Libraries**: framer-motion 用于卷轴展开;Tailwind 用于面板;SVG inline 用于分镜
- **Mobile considerations**: 长卷在移动端改为**竖向滑动**(从上到下浏览工序),保留卷轴隐喻;触摸长按分镜格放大

## Cross-component connection

1. **稀有度光晕**: 国宝级器物在工艺矩阵中带金光;失蜡法 + 国宝级的件物(如曾侯乙尊盘)是双重稀缺,特别标记
2. **形制 × 工艺矩阵**: 与 `form-genealogy.md` 联动 — 形制谱系树点击某子型 → 矩阵高亮显示该子型在哪些工艺下出现
3. **铸造者档案**: 工艺的发明 / 集大成者(如失蜡法巅峰 = 曾侯乙工匠群)可链接到 `caster-profile.md`
4. **时代联动**: 工艺长卷的解锁通常意味着"该时代登场" — 失蜡法解锁 ≈ 春秋战国登场,有时代感的暗示

## Persona differentiation

- **A 考据派**: 分镜格旁有"考古证据" — 殷墟出土的陶范、铜渣、坩埚照片或线描,标注引用;每个工序点击展开可见学术争议("失蜡法的中国起源时间至今争议:有学者认为春秋战国本土发明,有学者认为受西亚影响,详见李学勤 1996");支持"导出为 PDF 工艺谱"
- **B 沉浸派 ★(这是 Builder B 最能发挥的组件)**: 分镜画使用**全手绘国画风格**,工匠的衣袍、工具、火光、汗水都画出来;卷轴展开有"嗖"的音效占位 + 古琴轻响;每格附一段叙事"商代铸鼎,工匠百人,半年方成。火光照亮工匠脸上的汗与喜悦";解锁动画是"古卷从天而降、徐徐展开"3 秒史诗感
- **C 探索派**: 长卷面板上每条卷子是一张"技能卡牌";解锁有特效粒子和"叮"音;有"工艺速通"挑战(连续点亮 3 个工艺);可分享"我已掌握 3/6 古代工艺"卡片;失蜡法卷子在未解锁时显示"传说中的工艺,只有少数人见过它"诱发感

## Don't do these

1. **不要把工序做成步骤列表 / Stepper UI** — 长卷的横向、卷轴感是这个组件的灵魂,绝不能退化成 1-2-3-4 的步骤指引
2. **不要用照片做分镜** — 国画线描的笔触承载古代工艺的时间感;真实照片会破坏氛围(陶范的照片可以单独在引用区出现)
3. **不要让"卷起"状态太简单灰显** — 卷起来必须有视觉重量(卷轴杆 + 透视感),让用户真的觉得"这是个等我去打开的卷轴"
4. **不要把解锁做成 toast 弹窗** — 解锁长卷应该是**正式的、有仪式感的展开动画**,3 秒以上,可跳过但不应草率
