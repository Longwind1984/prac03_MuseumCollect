# Pilgrimage-Passport — 馆藏地维度 (朝圣护照 + 印章本)

## One-line purpose
把"馆藏地"从信息维度翻转成**承诺维度** — 用户不是在查"这个东西在哪",而是在记"我答应过自己要去见它"。护照 + 印章是把地理变成行动的物质载体。

## Visual description

视觉模型完全模仿**日本国铁駅スタンプ本 / 四国八十八札所朱印帳**:**长方形竖版折页**,封面是仿做旧米黄牛皮纸 + 朱砂烫印"博古护照 / Connoisseur Passport",右下角有"甲编 · No. 00837"小字编号(随机生成,固定个体)。

打开护照,**左右双页对开**:左页是已盖章馆藏列表(印章实体可见),右页是该馆收藏件物预览。

**关键视觉细节**:
- 每个馆有**独一无二的印章图案**(由 Designer 定义,共 9 个):
  - 国博 = 鼎纹方印(后母戊鼎轮廓)
  - 故宫(北京)= 太和殿剪影印
  - 台北故宫 = 翠玉白菜剪影印
  - 上博 = 大克鼎纹圆印
  - 河南博 = 莲鹤方壶仙鹤印
  - 陕历博 = 何尊"中国"二字印
  - 湖北博 = 编钟纹长印
  - 三星堆 = 纵目面具印
  - 大英博物馆 = 罗塞塔碑剪影印(海外篇泛黄)
- 印章实体是**红色国朱(#A02C2C)**,带做旧拓印感的非完全均匀边缘
- **海外篇页签泛黄做旧** — 纸张底色降饱和 + 加做旧滤镜
- 待启程的馆显示**朱砂淡虚线"待"字章** — 不是空白,是"等你"

## Interaction behavior

- **默认状态**: 护照封面闭合,点击翻开 → 露出左页(已盖馆)+ 右页(选中馆默认是最近盖章馆)
- **Hover 已盖馆条目**: 该印章发出极淡金色微光,文案附加"上次盖章 2026-04-12,你已收藏 4 件"
- **Click 馆条目**: 右页同步切换为该馆预览
- **Click 印章实体放大区**: 印章占满屏幕做"放大查看"3 秒,适合分享截图
- **Click "待启程"馆**: 弹出小提示 — "[陕历博] 在西安。现存你尚未见过的 [何尊·利簋·虢季子白盘] 等 5 件。最近一班开往西安的高铁 → " (mock,但暗示真实行动钩子)
- **Long-press 印章**: 弹出"撕下来"动作 — 单独把该印章生成一张分享卡片
- **滑动翻页**: 多个馆超过一屏时,左右滑动翻页(像真护照)
- **Transitions**: 翻页是真实折页动画(CSS perspective + rotateY 800ms)

## Data requirements

**Required fields from `bronze-treasures-v1.json`**:
- `current_museum`(用于馆归集,需要做名字规范化:如"中国国家博物馆"=国博)
- `id`、`name_zh`、`rarity_level`
- `excavation_site`(用于"出土地→馆藏地"叙事跳转)

**Derived data**:
- `museum_pool{museum: [ids]}` — 每个馆 mock 数据池
- `museum_collected{museum: [collected_ids]}` — 用户已收藏
- `museum_stamp_data` — 9 个馆的印章 SVG path + 配色 + 称号映射
- `museum_first_stamp_date{museum: date}` — 首次盖章日期(用户行为产生)

**User state**:
- `user.museum_visits{museum: [{date, ids}]}` — 每次"盖章"的记录(行为来源:扫描 / "我去过"按钮)
- `user.passport_id`(护照编号,生成一次)

## Game mechanic hook

- **承诺感 > 完成感**: 印章本的心理钩是"我还没去过,我应该去",不是"我集满了"。每个待启程馆都是一个**真实生活中的未完成承诺**
- **海外篇的情感落差**: 海外馆单独成篇 + 泛黄页面,文案"本应在家",不需要煽情,情绪自动产生
- **印章解锁层级**: 单馆首章 = 普通印 / 集齐该馆 80% = "常客"金印 / 集齐 9 大馆 = "九馆朝圣者" 终极印
- **跨馆联动**: 你已盖国博 4 件 → 提示"国博与陕历博合作过 X 件 X 朝展览,陕历博尚有 [何尊] 等你"
- **稀缺印章**: 三星堆印章 / 大英博物馆印章 比国博印章更稀缺,获取展示稀缺感

## Implementation hint

- **Tech**: HTML + CSS(护照纸张感用 `box-shadow` 内嵌 + 米黄渐变 + noise texture)+ SVG(印章实体)+ framer-motion(翻页动画)
- **Approximate complexity**: moderate(9 个印章 SVG 是设计工作量,但实现简单)
- **Libraries**: framer-motion 用于翻页和印章放大;Tailwind 用于布局;一份 noise.svg 做纸张纹理
- **Mobile considerations**: 护照在移动端改为**单页全屏 + 滑动切换** ,不再是双页对开;印章放大查看仍保留

## Cross-component connection

1. **出土地 ↔ 馆藏地双地图叙事**: 与 `ancient-map.md` 配对 — 一件器物有两个地理坐标(出土地 = 它的诞生地 / 馆藏地 = 它现在的家),用户能看到这件器物"漂流了多远"
2. **稀有度光晕**: 国宝级件物所在馆,印章周围有金边
3. **铸造者档案**: 妇好系列分散在国博和河南博,护照视图能看到"妇好的器物现在分散在 X 个馆"

## Persona differentiation

- **A 考据派**: 印章本字段更全 — 馆藏号、入藏时间、调拨史(如"大盂鼎 1959 由南京调归国博");每个印章可右键复制完整馆藏馆号 + BibTeX 引用("中国国家博物馆藏 No.K9999, 见《国博图录》1976 卷")
- **B 沉浸派**: 印章本封面有手写题字"博古护照"(书法字体);每次盖章有**毛笔落纸**动画 + 朱砂晕开效果;海外篇有更长的叙事文案(每件流散文物配一段流亡史:如圆明园流散史、抗战南迁史)
- **C 探索派**: 印章可"撕下来"做表情包;集齐 3 馆解锁"装腔三剑客"称号(梗感);每个印章背后是抽卡式翻面动效 — 翻过来看见该馆"镇馆之宝"的卡牌;海外馆叫"海外篇"听起来像 DLC

## Don't do these

1. **不要做成"你去过哪些 App 主页"的访问历史** — 朝圣 ≠ 浏览;盖章必须有"承诺-达成"的语义重量
2. **不要把印章做成游戏化的"奖章勋章"风格** — 视觉根植于"駅スタンプ + 朱印帳"传统,不是游戏 badge
3. **不要让海外篇泛滥成政治煽情** — 情感来源于"本应在家"的克制,不要加"屈辱"等过激文案
