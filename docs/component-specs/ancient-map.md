# Ancient-Map — 出土地维度 (古国漫游地图)

## One-line purpose
把"出土地"从"河南省安阳市"这样的现代行政区,翻译成**商代/周代/战国的古国版图上的探险地图**,用户每次打开都是一次"穿越扫坑"行为。

## Visual description

底图是**商-周-战国可切换的古地图**风格(参考清代《禹贡九州图》或汲冢《竹书纪年》示意图的笔法):水墨山形 + 虚线疆界 + 毛笔国名标签(殷·周·楚·齐·越·秦·古蜀)。**山川河流不变,但古国边界与国名随时代轴切换而重排**。这是这个组件的核心张力。

每个考古遗址点是一个**毛笔点描+小篆标签**的圆点,共 15-20 个标记(殷墟、周原、丰镐、二里头、二里岗、三星堆、金沙、盘龙城、新干大洋洲、晋·侯马、楚·江陵、曾·随州、齐·临淄、秦·凤翔、越·绍兴)。海外馆藏在右下角单设一个"流散海外"小方框,内含 MET / 大英 / 弗利尔 等剪影。

**关键视觉细节**:
- 切换时代时,**国名标签的小篆字体不变,但位置漂移**(殷在商代有,周不在;战国时殷消失,楚齐秦显)— 动画约 800ms
- 已踏足的点不是普通图钉,是该遗址代表器物的**微型毛笔速写图标**(二里头 → 爵的剪影;三星堆 → 纵目面具剪影;殷墟 → 鼎的剪影)
- 未踏足的点是**虚线圆圈 + 问号**,鼠标悬停浮出"召唤"
- 国宝级出土地(殷墟、三星堆、曾侯乙墓)有**金色微光晕**渗透叠加(见 `rarity-halo.md`)

## Interaction behavior

- **默认状态**: 显示当前用户**主时代**的版图(根据时空柱判断,如用户收藏多集中商晚期则默认显商代版图)
- **Hover 已踏足点**: 浮出小卡片 — 遗址名 + 代表器物缩略图 + "你已收藏 3 件 / 该地总 5 件"
- **Hover 未踏足点**: 浮出"召唤"卡片 — "[古蜀],你尚未踏足。这里出土过 3 件国宝(三星堆青铜大立人、纵目面具、青铜神树),与殷墟同时存在" + 灰色剪影
- **Click 遗址点**: 弹出该地"考古笔记本" — 1976 妇好墓发掘 / 1986 三星堆祭祀坑发现 / 1978 曾侯乙墓发掘 等故事 + 该地件物列表
- **Drag 地图**: 整张地图可平移(SVG transform)
- **Wheel zoom**: 缩放级别 0.5x – 3x,放大后细节遗址点显示更详
- **顶部时代轴 Click**: 切换底图古国版图,过渡 800ms,国名漂移动画
- **左下角模式开关**: [个人足迹] / [全国宝分布] 切换 — 后者显示所有 mock 数据点位,前者只显示用户已收藏过的

## Data requirements

**Required fields from `bronze-treasures-v1.json`**:
- `excavation_site`(用于地图坐标查询)
- `ancient_state`(古国名,用于时代切换时正确归属)
- `dynasty` + `period`(用于时代轴切换时显隐)
- `id`、`name_zh`(用于点位关联与详情跳转)
- `rarity_level`(国宝级遗址金光)

**Derived data**:
- `site_coords{site_name: [lon, lat]}` — 一份遗址名到坐标的查表(由 Designer 提供 mock,约 15 条)
- `site_pool{site: count}` — 每个遗址 mock 数据池件数
- `site_collected{site: count}` — 用户已收藏该地件数
- `dynasty_borders{dynasty: SVG_path}` — 每个朝代的古国边界 SVG path(简化,约 6 套)

**User state needed**: `user.collected_ids[]`,`user.current_view_dynasty`(地图当前显示哪个时代版图)

## Game mechanic hook

- **空白点的呼唤**: 未踏足点周围 hover 时,浮出"剪影 + 召唤文案",诱发"我想去补这个地方"
- **海外篇的情感钩**: 右下"流散海外"框泛黄做旧,鼠标悬停文案 "本应在家" — 不需要煽情,信息本身即情绪
- **集齐遗址解锁**: 集齐"商三大遗址"(殷墟 + 盘龙城 + 三星堆)→ 段位 "三家朝圣者";集齐周原 + 丰镐 → "西周王畿足迹";集齐六国(晋楚曾齐秦越)→ "六国漫游者"
- **稀有遗址特别标记**: 三星堆 / 古蜀这类独立文明遗址在地图上**金色 + 描红边**,踏足时有专属解锁动画

## Implementation hint

- **Tech**: SVG 全图(底图、点位、边界路径都是 SVG),用 D3.js 做缩放/平移变换,framer-motion 做点位入场和时代切换的过渡
- **Approximate complexity**: hard(古国边界 SVG path 是工作量重点)
- **Libraries**: D3.js geo + zoom + transition;Tailwind 用于面板;CSS filter `drop-shadow` 做金光晕
- **Mobile considerations**: 触摸 pinch zoom 必备;时代轴在移动端改为底部 swipe 切换;遗址点 hit area 至少 44x44 px

## Cross-component connection

1. **时代 × 出土地(组合 A)**: 与 `time-pillar.md` 双向联动 — 时空柱点击 → 地图切换;地图点击遗址 → 时空柱该期高亮。这是产品的"标志组合"。
2. **稀有度光晕**: 国宝出土地点位金光晕(见 `rarity-halo.md`)
3. **铸造者档案**: 殷墟点位 hover 时,如已收藏妇好系列,卡片底部出现"妇好" 头像入口,跳转到 `caster-profile.md`
4. **馆藏地朝圣**: 与 `pilgrimage-passport.md` 形成"出土地→馆藏地"的双地图叙事(器物的两个家)

## Persona differentiation

- **A 考据派**: 底图改用《禹贡九州图》风格的精确学术古图,边界 path 引用考古学界主流复原方案(《中国历史地图集》谭其骧编);遗址点悬停卡片显示发掘年份、领队、报告引用(如"妇好墓:1976,郑振香,《考古》1977-1");可切换"基于报告 / 基于推测"两种边界模式
- **B 沉浸派**: 底图用水墨晕染,山形是 brushwork 风格;时代切换时不是过渡,是"卷轴展开/收起"动画,配古琴音占位;hover 遗址点浮出该地"出土那一天"的叙事文案("1976 年,郑振香蹲在妇好墓口,看见第一件鸮尊出土的那个清晨")
- **C 探索派**: 底图饱和度更高,国名用毛笔但配色更鲜艳;每次点亮新遗址有粒子爆炸 + "扫坑成功!" toast(可关);可切换 "宝可梦图鉴模式" — 地图上每个已踏足点变成卡牌排列;有"挑战"按钮:"再点亮 2 个就获得'三家朝圣者'徽章"

## Don't do these

1. **不要用现代中国地图**— 这个组件的灵魂在古地图。用百度地图皮的瞬间产品就死了
2. **不要做"红色高亮 + 蓝色未亮"的儿童配色**— 颜色语言要在水墨青铜的克制范围内
3. **不要把海外馆藏简单灰显**— 流散海外不是"灰",是"泛黄做旧的另一张纸",有自己的情感重量
