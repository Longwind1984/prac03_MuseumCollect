# Rarity-Halo — 稀有度维度 (国宝光晕 + 印章) ★ 全局视觉层

## One-line purpose
**这不是一个独立组件,这是一个全局视觉系统**。稀有度不在某个页面里,它**渗透在所有其他 9 个组件上**: 时空柱里的国宝段闪金、地图上国宝出土点金圈、谱系树上国宝子型金边、对照墙上国宝卡金光、铭文页国宝铭"国之重器"红章。它是产品的"血液色彩"。

## Visual description

**4 档稀有度梯度**(克制递进,不像游戏的紫橙红):

**附加稀有标签**(以小印章形式叠加在卡片上,可同时多个):

**重要原则**: 一级以下基本无光效,只在国宝级以上才出现明显光晕。**克制 = 高级**。

## Interaction behavior

这个系统**没有用户主动操作**,它是被动渲染层。但有几个一致的交互:

- **Hover 任意带光晕的器物卡**: 浮出小气泡 "国之重器 · 2002 年首批禁止出境 · 编号 K9999"
- **Click 国宝级器物**: 进入器物详情页时,有 **3 秒的"国之重器" 入场动画** — 红章入框、金光环绕、文案"这是国家不允许出门的级别"(可关)
- **首次解锁国宝**: 全屏播放 3 秒**克制的祝贺动画** — 朱砂红章从天而降盖印 + 文案"你的第 1 件禁出境国宝" + "分享" 按钮
- **国宝率仪表盘**: 在 `me.html` 页有专门的"个人收藏稀有分布雷达图":你的国宝率 14% / 行业平均 4% / 国宝率排名 前 15%

## Data requirements

**Required fields from `bronze-treasures-v1.json`**:
- `rarity_level`(关键字段:"国宝" / "一级文物" / "二级文物" / "三级文物" / 字符串可能含括注如"国宝(2002年首批禁止出境文物)")
- `id`、`name_zh`

**Derived data**:
- `rarity_tier{artifact_id: tier}` — 解析后的稀有度档(1-5)
- `rarity_tags{artifact_id: [tags]}` — 附加标签数组("孤品"/"长铭"/"流散海外"/"列鼎组合"/"古蜀"/"禁止出境")
- 标签判定逻辑(由 Designer + Data Engineer 商定):
  - "长铭" = `inscription.char_count >= 100`
  - "孤品" = 该 form_subtype 在 mock 数据池中仅 1 件
  - "流散海外" = `current_museum` 在海外馆列表中
  - "古蜀" = `ancient_state` 含"蜀"或 site 含"三星堆/金沙"
  - "禁止出境" = `rarity_level` 含"禁止出境"

**User state**:
- `user.rarity_distribution` — 用户收藏的稀有度分布(用于雷达图)
- `user.first_treasure_unlocked_date` — 首件国宝解锁日期(用于"分享"动画的"已 X 天")
- `user.shared_treasures[]` — 已分享过的国宝列表

## Game mechanic hook

- **Rarity hook ★★ (全局乘数)**: 稀有度是渗透每个组件的视觉层,用户在任何页面都能"瞬间感知 — 这里面有多少金子"
- **Identity hook**: 国宝率 (国宝级在收藏中的占比) 是个人收藏的"含金量"指标,用户会下意识炫耀
- **Story hook**: 每件国宝有"国之重器"叙事 — 为何被列入 195 件禁出境名录,从政治/历史/学术三个角度的入选理由
- **首次国宝的 social moment**: 用户首件国宝解锁后 7 日是天然的分享黄金期 — 截图分享率应 > 30%(motivation-hooks 已定指标)
- **附加标签的稀缺感叠加**: 一件器物可能同时是"国宝 + 长铭 + 流散海外 + 禁出境" 四重稀缺,卡片上 4 个小印章叠加,这种"稀缺密度"是产品高级感的来源

## Implementation hint

- **Tech**: 纯 CSS + SVG。光晕用 CSS `box-shadow` + `filter: drop-shadow()`;龙纹光晕用 SVG path + CSS `@keyframes rotate`;印章是 SVG inline
- **Approximate complexity**: trivial-moderate(技术不难,设计要精细)
- **Libraries**: 不需要重型库;CSS keyframes 即可
- **Mobile considerations**: 龙纹光晕的动画在低端机可降级为静态金边;移动端不显示流光(性能成本)
- **关键 CSS 类**(供 Builder 复用):
  ```css
  .rarity-treasure { /* 国宝 */
    box-shadow: 0 0 24px rgba(212, 168, 87, 0.6), 
                0 0 48px rgba(212, 168, 87, 0.3);
    border: 2px solid #D4A857;
    position: relative;
  }
  .rarity-treasure::before { /* 龙纹光晕(SVG) */ }
  .rarity-treasure::after { /* 禁出境红章 */ }
  .rarity-tier-1 { /* 一级 */
    box-shadow: 0 0 12px rgba(201, 168, 95, 0.4);
    border: 1px solid #C9A85F;
  }
  .rarity-tier-2 { /* 二级 */ border: 1px solid #8A4F8A; }
  .rarity-tier-3 { /* 三级 */ border: 1px solid #5C7A99; }
  .rarity-tier-common { border: 1px solid #6B6B6B; }
  ```

## Cross-component connection

**这个组件本身就是"连接"** — 它叠加在所有其他 9 个组件上:

1. **时空柱**: 国宝段落填充色更深沉、有微金光;段头国宝印章数显示
2. **古国地图**: 国宝出土地点位金圈;国宝标签密度热图
3. **朝圣护照**: 国宝级件物的印章带金边
4. **形制谱系**: 国宝子型节点金边;对照墙上的国宝卡片金光
5. **纹饰演化**: 国宝独有纹饰节点金光;拓片本里的国宝拓片底色泛黄
6. **场景重建**: 国宝归位时金光更强烈;集齐全国宝的场景有金色全景
7. **工艺长卷**: 失蜡法 + 国宝(曾侯乙尊盘)双重稀缺标签
8. **铭文释读**: 史诗铭金标;"宅兹中国"等特殊铭文有专属印
9. **铸主档案**: 妇好系等"传奇铸主"档案卡有金边

**这是 rarity 系统的灵魂 — 它不在某处,而在每处。**

## Persona differentiation

- **A 考据派**: 稀有度面板做成**严肃数据视图** — 三级文物 / 二级 / 一级 / 国宝 / 禁出境 的法律定义出处展示;每件国宝的"入选 195 名录"原因有官方文献引用;雷达图改为统计学严谨的 box plot;**避免任何"金光闪闪"特效**(对 A 考据派而言光晕过于游戏化,只保留**克制的金边 + 朱砂印章**,不要旋转龙纹)
- **B 沉浸派**: 稀有度光晕**满血开放**,但用"古典"语汇 — 不是游戏粒子,是**香烟、烛火、檀香光晕**的暖色感;首件国宝解锁动画是"幕布徐徐拉开,朱砂红章从天而降盖印"3 秒电影感;每件国宝的"为什么入选 195"用文学化叙事
- **C 探索派 ★(稀有度是这个 persona 的核心钩子)**: 光晕**最炸裂** — 国宝级有金色粒子动画(模拟原神五星抽卡光效),龙纹旋转更快,流光更亮;首件国宝有"开盲盒"3D 翻面动画;一键生成"我抽中了 X 件国宝"分享卡;有"我比 17% 用户先收到这个国宝"的稀缺感文案

## Don't do these

1. **不要用★★★★★ 五星稀有度**— 这是游戏 UI,会让博物馆爱好者瞬间删 App(persona A 红线之一)
2. **不要让光晕过于花哨**— 一级以下没光效,只有国宝级以上才有明显光晕。**"克制 = 高级"是这个组件的不可动摇原则**(C 探索派除外,但即便 C,光晕的视觉根植于"龙纹/朱砂/云雷"传统语言)
3. **不要把稀有度做成独立"国宝列表"页**— 那只是一个查询;稀有度必须在每个组件视图里渗透,不能页面化
4. **不要把"国宝率"做成排行榜竞赛**— 自我对照而非他人比赛,这是博物馆爱好者的红线;C 探索派可允许"本地朋友圈对比",但不可全局排行榜
5. **不要忽略附加标签的视觉重量**— 8 个附加标签(孤/长铭/流/列/蜀/战/禁/...)每个都有自己的小印章,这是 rarity 系统的"细节深度"
