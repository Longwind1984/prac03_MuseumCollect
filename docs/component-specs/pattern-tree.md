# Pattern-Tree — 纹路维度 (纹饰演化树 + 拓片放大镜)

## One-line purpose
把"纹路"从"装饰"翻译成**思想的视觉编码** — 用户在演化树上亲眼见证"神权(饕餮) → 礼制(窃曲) → 写实(凤鸟)"的转变,在拓片放大镜里训练自己的眼睛,从"那个有眼睛的"升级到"这是双身夔龙"。这是产品最学术、最杀手锏的一个组件。

## Visual description

**两层结构**:
1. **演化树 (Pattern Evolution Tree)** — 不是单纯分类,是带**真实考古学传承关系**的演化谱:饕餮纹 → 顾首夔龙 → 窃曲纹(西周晚抽象化)→ 重环纹(春秋早) 这条线是有考据的。
2. **拓片放大镜 (Rubbing Loupe)** — 单件器物视图下,用户长按器物图 → 出现毛笔风格圆形放大镜,框选区域 → 系统识别"这是窃曲纹"→ 自动"拓"下一片黑白拓片入收藏。

**关键视觉细节**:
- 演化树的节点是**真实纹饰的剪影**(SVG path 速写,不是文字)
- 演化连线是**毛笔风格弧线**,体现"演变"不是"分类",粗线 = 主流传承,细虚线 = 旁支
- 已点亮节点是**深青铜色 + 纹饰图案清晰**,未点亮是灰虚线 + 剪影
- 拓片是**黑白做旧**,带宣纸纹理 + 拓墨的不均匀感
- 国宝级独有纹饰(如鸱鸮纹仅妇好系)节点有金色微光晕

## Interaction behavior

- **演化树默认状态**: 全屏树,显示所有节点,以时代轴为 x 轴布局
- **Hover 节点**: 浮出气泡 "饕餮纹 · 神权时代主流 · 你在 3 件器上识别 · 累计拓片 7 张"
- **Click 节点**: 跳出该纹饰的**跨器物对照墙** — 你所有有此纹饰的器物缩略图并列,纹饰局部放大并排比对
- **拓片放大镜激活**: 在单件器物详情页(`artifact.html`),长按器物图 1 秒 → 出现圆形放大镜,光标变拖框
- **拖框选择**: 在器物上拉框,框内是放大特写
- **释放框**: 系统 mock 识别 → 0.8s 后弹出识别结果 + "拓片入册 +1"动画(纸张从下方飞入)
- **Click 拓片**: 跳到演化树,该节点高亮 + 触发节点闪烁动画
- **Transitions**: 节点点亮是**墨水晕染**效果(SVG filter feGaussianBlur from blur=8→0,800ms);拓片入册是纸张飞入 + 朱砂签章

## Data requirements

**Required fields from `bronze-treasures-v1.json`**:
- `patterns[]`(每件器物的纹饰标签数组,如 ["饕餮纹", "夔龙纹", "云雷纹"])
- `dynasty`、`period`(用于演化树时代轴定位)
- `id`、`name_zh`(用于关联和跳转)

**Derived data**:
- `pattern_genealogy{}` — 一份 hand-curated 的纹饰演化图(节点 + 演化边),约 30 个节点(由 Researcher 提供考据,Designer 提供视觉)
- `pattern_pool{pattern: [ids]}` — 该纹饰出现在哪些 mock 数据件物上
- `pattern_recognized{pattern: count}` — 用户识别次数
- `pattern_first_recognition_date{pattern: date}` — 首次识别时间,用于"点亮"动效记忆

**User state**:
- `user.rubbings[]` — 拓片本,每张拓片 = {pattern, source_artifact_id, region_coords, date}
- `user.pattern_titles[]` — 已解锁的纹饰称号

## Game mechanic hook

- **Identity hook (主)**: 集齐某分支所有节点 → 获得**"凤鸟收藏家 / 饕餮鉴定师 / 窃曲修士"** 等纹饰称号,这是产品最响亮的身份系统(挂在用户头像旁的角标)
- **Connection hook**: 拓片本里同纹饰跨器物的"纹饰家族"自动聚合 — 你能看出"饕餮纹在后母戊和龙形觥上长得不一样"
- **Story hook**: 演化树本身是叙事 — 神权(商) → 礼制(西周) → 写实(春秋战国)三阶段。展开 = 故事
- **Completion hook**: 演化树末梢分支(如"蟠螭纹")需该分支所有上游节点都点亮才能解锁
- **稀有纹饰**: 鸱鸮纹(仅妇好系)、虎噬人头纹(仅后母戊系) 单独标"稀有纹",拓片本里展示有特殊金边
- **训练眼睛**: 拓片放大镜不只是收集,是**训练用户的鉴别能力** — 用户拖框次数越多,系统对"用户已识别哪些视觉特征"的画像越精准

## Implementation hint

- **Tech**: D3.js 自定义 force layout 做演化树(因为时代轴 x + 上下分支 y 是 2D 布局,非纯树)+ SVG 拓片渲染;拓片放大镜用 Canvas 做局部 zoom(对器物图采样 + 滤镜)
- **Approximate complexity**: hard(演化数据 curation 是最大成本,UI 实现 moderate)
- **Libraries**: D3.js force + zoom;Canvas 2D 用于拓片局部裁剪和黑白滤镜(`filter: grayscale(1) contrast(1.4)`)
- **Mobile considerations**: 演化树在移动端**改为竖向时代轴**(从下到上)+ 节点放大;放大镜用 touch drag,不是鼠标 hover

## Cross-component connection

1. **纹路 × 时代(组合 C)**: 与 `time-pillar.md` 横轴对齐 — 演化树时代轴和时空柱的朝代段一一映射,任一组件 hover 时代 → 另一组件高亮对应纹饰/朝代。详 motivation-hooks.md §3.3。
2. **稀有度光晕**: 国宝独有纹饰节点金光
3. **铭文**:演化树的"金文体演变"是单独的子族(可选扩展),把纹饰与铭文的字体演化做关联
4. **形制谱系树**:同一件器物可同时属于"方鼎"节点和"饕餮纹"节点,跨树跳转

## Persona differentiation

- **A 考据派**: 演化树带**真实考古学引用** — 每条演化连线点击展开,显示主流学派(李学勤说 / 张光直说 / 容庚说)的依据;每个节点的演变定义有"参考文献"小标(《商周青铜器纹饰》P.234);拓片本支持导出为 PDF 拓本集 + BibTeX
- **B 沉浸派**: 演化树底色是**做旧米黄+水墨晕染**,纹饰节点是**毛笔速描**;hover 节点浮出一段文学化文案"饕餮:一张张着血盆大口的脸,是商人为神塑造的容貌";拓片入册有"墨色晕开 + 朱砂签章"动效 + 古琴音占位
- **C 探索派**: 演化树有"技能树"游戏感 — 点亮节点有粒子,集齐分支有 fanfare 弹窗 "🎉 凤鸟纹大宗师 解锁";称号挂在用户头像旁可炫耀;拓片本支持"导出为壁纸"和"分享到小红书"模板;有"我的稀有纹饰排行"

## Don't do these

1. **不要做无考据的"乱连线"演化树**— 这是产品最学术的组件,连一条错的演化都会让 A 考据派删 App
2. **不要把拓片做成"截图保存"**— 拓片必须有**黑白做旧的拓印感**,这是这个组件的视觉灵魂
3. **不要在拓片本里放彩色器物图**— 拓片就是拓片,黑白宣纸,不要混入彩色,会破坏氛围
4. **不要把称号弹窗做成花哨彩带**— 称号是这个组件的核心 identity hook,出场要克制(类似古书"加印"的安静感)
