## 1. Dimensional map review

读完 `docs/dimensional-map.md`,我的第一反应:**这份文档是过去两年我看到的最体面的青铜器领域 product taxonomy 了。**它没掉到"维基条目清单"陷阱里,真的去想"形态如何承载意义"。但作为做这行的人,我有几个具体的意见:

### 1.1 10 个维度是否正确?

**整体:对。** "时空层 / 器物层 / 价值层" 三层分类是经得起推敲的。维度的颗粒度也合适——再细就脱离产品,再粗就失焦。

**但有两个真问题:**

**(a) "形制"维度独立于"用途"是个权宜之计,不是学术正解。**
青铜器分类的核心矛盾是:**"鼎"既是 form 又是 function**。考古学常说"以用类型,以型分期"(form 用来断代,function 用来定礼制),你不应该把它们分成 §4 和 §6 两个平行维度。**正确的做法是: function 是 form 的上位 dimension**(炊器 > 鼎 > 圆鼎/方鼎),而你现在把它们做成"形制谱系树"和"礼器归位"两个独立组件,会让用户在两个组件里看到同一个"鼎"出现两次,语义重复。

→ 这点在 dimensional-map §11 组合 B (形制 × 用途) 你们自己也意识到了,但提出的解法是"双向绑定",其实没解决根本问题。我会重新想这个层次结构。

**(b) "工艺"和"纹路"作为两个独立 P0/P1 维度,理论上正确,实践中冗余。**
纹饰的演变(饕餮→窃曲)其实是**工艺能力变化的结果**——商周范铸法能做出连体兽面,失蜡法到来才能做透空蟠螭。**两者深度耦合**。你做成两条独立的可视化(纹路演化树 + 工艺长卷),没有交叉视图,等于把同一件事说了两遍。

→ 我会在 v2 加一个"纹饰-工艺"双轴矩阵作为高级研究视图。

### 1.2 推荐的产品形态是否得体?

- **时空柱"高度严格 ∝ 朝代时长"** — 这是这份文档最漂亮的洞察。学考古的人都知道商代 554 年这件事让人发懵,而西周只有 275 年。但 90% 的科普 timeline 把它们画成等长。**做到了这一点,你就 already 拉开了和故宫 App 的差距**。
- **古国漫游地图 with 时代切换的版图变化** — 学术上完全成立。商代版图、西周版图、列国版图,确实"山川河流不变,边界在变"。这是历史地理学的常识,但产品上很少人愿意做。**这个做对了**。
- **铭文释读器 + 段位制** — 这是这个 spec 里最让我激动的部分,因为它把铭文从"展品说明"升级到"长期学习曲线"。但段位的阈值(50/150/400/1000 字)我没看到引用依据。**金文识字段位制是你们发明的,不是学界公认的**——这没问题,但用户档案里应该写明"本 App 自创段位标准"。

### 1.3 跨维度组合的学术合理性

- 组合 A (时代 × 出土地) — **合理。**殷墟商晚和三星堆古蜀并存是常识,但产品化做得好就值钱。
- 组合 B (形制 × 用途) — 见上面 1.1(a),概念重复。
- 组合 C (纹路 × 时代) — **合理且必要。**夔龙→窃曲是西周中晚期演化的核心事件。
- 组合 D (铭文 × 铸造者) — **合理,但产品成本会很高。**金文人名识别在学界都还在做大数据,你们要做的是 mock。

### 1.4 缺的维度

我会加 **§11 "断代依据" (Dating Evidence)** —— 这是考古最硬核的部分:**为什么这件是商晚期而不是商中期?**(地层学 / 同墓器物 / 铭文人名 / 字体阶段 / 14C)。`prd-demo-night.md` 没把这个做成 first-class dimension,而是把它埋在每件器物的字段里(`approx_year`)。对硬核用户,这是最大的漏。

## 3. Per-demo content review

### 3.1 A 考据派 (v1-A-textual-research) — **内容深度最配得上"硬核"招牌**

**强项:**
- **每条记录都有 `data_sources` 字段并在 artifact.html 渲染为"出处与引用"表格**。这是 25 个国博 / 故宫 App 都做不到的。陈翊安看了会觉得"终于有人认真做了"。
- **铭文释读器**真的把每个字做了字源 + 异体字 + 引用(JINWEN_DICT 在 data.js)。虽然只覆盖 ~20 字,但"中"、"国"、"宅"、"兹"四字在何尊的处理是教科书级。
- **后母戊 vs 司母戊 释读争议** 在 index.html 第 122 行明确列为"近期发现"并标 citation。**这是博士生会兴奋的细节**。
- **CSL/BibTeX 导出按钮** ("复制 BibTeX") — 极度懂用户。我自己每天用 Zotero 整理文献,看到这个按钮我会立刻打开 Notion 装上去。

**弱项:**
- **断代依据(地层 / 同墓 / 字体 / 铭文人名)从未被作为一级信息暴露**。每条记录写了"商代晚期"但**没说为什么是晚期不是中期**。考据派要的不是"标签",是"标签的依据"。这是 P0 缺失。
- **引文格式不规范**。比如 `"马承源 1988"` —— 1988 年的什么?《商周青铜器分期标准器》? 《中国青铜器》?还是 《商周青铜器纹饰》? 引文形如 "Author Year" 但没书名/页码,**对真正的研究用户是无用的**。
- **形制谱系树写在 data.js 里是手写的几层 dict**(FORM_TREE),**没引学界标准 taxonomy** (如马承源系 vs 朱凤瀚系 vs 林沄系)。一个考据生看到这种"自造分类"会皱眉。

**评分:**内容深度 7/10,准确性 7/10,学术包装 8/10。**三个里最像样的**。

### 3.2 B 沉浸派 (v1-B-immersive) — **诗意可,事实底子也算扎实**

**强项:**
- **国宝独白(MONOLOGUES in data.js)的文学水准远超我预期**。"我是后母戊鼎。我的身体由二十八块陶范分铸再合,凝聚一千多个工匠的手温与火光"——**这种第一人称叙事既保留了 28 块陶范的事实,又有温度**,不是空洞的"我是国宝"自夸。
- 何尊独白"一九六五年,我被当作废铜,以三十块钱卖到了宝鸡的废品收购站。文物干部佟太放从一堆废金属里把我抢救出来。十年后,马承源在我尊底除锈——他看见了那一百二十二字铭文。" **这是把考据细节嵌入诗化叙事的范例**——既准确又能引发情绪。
- 莲鹤方壶独白引用郭沫若"乃时代之精神之一象征"的原句,**找到了真正的学术评价做支撑**,而非随手编一句感慨。
- 利簋独白把"夏商周断代工程定 BC 1046.02.20" 写进了诗化语境,**这是事实层不动摇的诗化**。

**弱项 / 错误:**
- ⚠ **P1 利簋独白文案错误**: "我被一位叫'利'的将领的器物" — **这是一句病句**。应改为"我是一位叫'利'的将领的器物"或"我属于一位叫'利'的将领"。文学性再强,语法错就漏了底裤。
- ⚠ **何尊独白把"宅兹中国"诠释为"这个国家最初的名字"** — 这是大众化处理,**严谨说"中国"在何尊里指的是"成周(洛邑)地区"或"天下之中",不是国名**。诗化文案这样写无大碍,但和学界共识有偏差。我也理解 B 版的目标用户(苏念,中文系)不会注意——但被陈翊安看到她会皱眉。
- ⚠ **妇好鸮尊独白说"妇好不是温柔,她是夜里看得清楚的人"** — 文学性很好,**但"夜里看清楚"是把鸮的现代符号解读硬贴回商代,这在考古学上没依据**。商代"鸮"的象征意义到底是什么(神鸟?战神?夜行者?死亡象征?),学界至今争论。这种诗化是 OK 的,但**应该有一句标"这是当代解读"**。
- ⚠ **散氏盘独白说"中国最早的土地契约"** — 学界主流说法是 "现存最早的土地契约金文记录",**但不是"中国最早的土地契约"**。商代甲骨文里有更早的土地交易记录,只是不在青铜器上。**P2 nuance**。

**评分:** 内容准确性 7/10,文学性 9/10,**最好的"诗化但不离谱"的范例**。

### 3.3 C 探索派 (v1-C-explorer) — **MEME 化处理用力,但稀有度逻辑会扁平化事实**

**强项:**
- 梗 quote 写得有意思: "我比国博还早 set up 这个 boss" (后母戊鼎)、"500 字铭文,抵得一篇《尚书》" (毛公鼎) — **这些 meme 不是空洞,是基于真实事实的提炼**。
- 何尊的 meme "'宅兹中国'四个字最早的爸爸,被废铜站当 30 块卖过" — **同时戳中两个事实点**(中国二字最早 + 废品站抢救),挺巧。
- 越王勾践剑 meme "埋 2400 年还能割纸,这是青铜还是 stainless steel?" — **保留了考古事实**(试纸而断的描述),但**有 P2 nuance 问题**:严格说不是"stainless steel"模拟,而是含锡量梯度 + 硫化处理。把它和 stainless steel 类比对内行人是好笑的(明显不是),对外行人是误导的(以为青铜=不锈钢)。

**弱项 / 错误:**
- ❌ **P1 稀有度扁平化**: state.js 把所有"含'国宝'"和"含'禁止出境'"的都映射为 `treasure` (rarityTier),其他一二三级都归为 tier-1/2/3 平级。**这种二分法忽略了"国宝中的国宝"——国家禁止出境名录 195 件/组 (2002/2012/2013 三批)** 才是真正的顶级。何尊、毛公鼎、越王勾践剑这些都属于禁出境名录,你们的数据 `rarity_level` 字段里也有 "(2002年首批禁止出境文物)" 标注——**但 C 的 rarityTier 函数把这一切扁平化了**。
- ❌ **P1 形制 taxonomy 错误**:state.js 的 GENEALOGY 把 "尊盘" 列为 "尊盘" 类型下的 "尊盘组合" 子型,与 "尊" 平级。**这是产品建模错误**:曾侯乙尊盘是"尊置于盘中的酒礼器组合",学术分类里"尊"和"盘"是两种 distinct 器型,"尊盘"是组合而非新器类。**应改为: 尊 < 尊盘组合(子型) 和 盘 < (无)** 各列一次,或者在产品里说清楚"这是组合器"。
- ❌ **P1 形制 taxonomy 错误**: GENEALOGY 里把 "簋" 的子型只写了"方座簋",**漏了"四耳簋"、"四足簋"、"附耳簋"等更常见的子型**。利簋自己就是"方座簋"+"四耳"+"贴耳"。把方座簋当作簋的唯一子型,是把"产品里有的器"反推为"分类系统"——**这是学术 taxonomy 和产品 taxonomy 的混淆**。
- ❌ **P2 nuance**:盛贮器分类错误。state.js 把铜瓿 ("siyangshou_bu") 归为"瓿 < 羊首瓿",**没问题**;但 catalog 的 type 字段写"酒器/盛贮器",**"盛贮器"不是青铜器分类的常用术语**,容易和"酒器"混。
- ❌ **P2 nuance**:meme "65 件套 4421kg,公元前 5 世纪的 BGM" 把编钟比作 BGM(背景音乐) — **从乐律学角度,曾侯乙编钟是宫廷雅乐的核心乐器,不是 BGM。BGM 暗示功能性辅助**。这是 Z 世代会觉得好笑、考据派会觉得轻佻的临界点。

**评分:** 内容准确性 5/10,文学性 7/10,**靠 meme 包装把内容压扁了。**

## 5. Things present that I would correct (as a domain expert)

### 5.1 把"鼎"归为"食器" (data 第 20、152、196、239、370、888 行)
学界主流把鼎分为"炊器(烹煮用)"和"食器(盛食/礼器用)"两种功能。**商周礼器中的鼎是炊器演化而来的礼器,严格说应归"炊器/礼器"**。`dimensional-map.md §4.1` 里你们自己把鼎归在"炊器(烹煮)",但 `bronze-treasures-v1.json` 里 6 件鼎都标"食器"。**前后矛盾**。

### 5.2 craft 字段措辞不严谨
- 莲鹤方壶 craft: "复合工艺(分铸、圆雕、浮雕、焊接,可能含失蜡法早期工艺)"。**学界主流认为莲鹤方壶尚未使用失蜡法,失蜡法在曾侯乙尊盘(战国早期 BC 433)才确证大规模使用**。莲鹤方壶用的是范铸法 + 分铸 + 焊接,**"可能含失蜡法早期工艺"是猜测,不是定论,应去掉或更严谨措辞**。
- 马踏飞燕 craft: "失蜡法 + 焊接"。**马踏飞燕的工艺至今未完全定论**,东汉时期失蜡法已成熟,但具体到这件是失蜡还是分铸有争议。写"主流说法为失蜡法"更稳。

### 5.3 后母戊鼎纹饰列表
data 写: `["饕餮纹", "夔龙纹", "云雷纹", "虎噬人头纹", "蝉纹"]`。**这个列表合并了主纹和辅纹**,且**"虎噬人头纹"不是后母戊鼎的特征纹饰**(那是虎食人卣的)。**后母戊鼎的辅耳上确实有虎噬人头纹饰,但严谨学术分类里这件器物以饕餮纹为主纹,虎纹只是耳部装饰**。把它和饕餮平级列出会误导。

### 5.4 妇好鸮尊"双足三点稳立"
data 写: "宽喙宽尾下垂,与双足三点稳立"。**"双足"+"尾"= 三足支撑是正确观察,但"三点稳立"这个说法是民间科普语言,不是学术语言**。学界说"以双足及尾呈鼎立之势"。

### 5.5 散氏盘 357 字
- 学界数字常引为 357 字或 350 字(算不算合文)。你们用 357 没问题,但应该 acknowledge "学界对字数有 350-357 范围内的不同算法"。

### 5.6 何尊铭文 122 字 vs "119 可识 3 字未释"
data 写得**专业**: `"122字(119字可识,3字未释)"`。但是注意:**学界主流说法是 119 字,你们的 122 字算了 3 个未释字**。这是非典型计法,**应该改为"119 字(其中 3 字漫漶不可释,另有学者算入未识共 122 字)"**。

### 5.7 商鞅方升 "公元前344年"
data 写 "约公元前344年(秦孝公十八年初铸)"。**秦孝公十八年是 BC 344 没错(秦孝公在位 BC 361-338)**。但**严格说是初铸,后秦始皇 26 年 (BC 221) 加刻诏文** — `period` 字段写得已经准了: "战国晚期秦国 + 秦统一后加刻诏文",**这是这条记录最专业的处理**。

### 5.8 长信宫灯 65 字铭文
data 写 65 字,但**学界常引用为 9 处刻铭共 65 字,而非一段 65 字**。这一点 inscription.summary 没说清楚。
