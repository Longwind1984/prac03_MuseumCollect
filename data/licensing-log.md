## 风险与缓解 (Risks & Mitigations)

### 高风险点
1. **四羊首铜瓿 (siyangshou_bu)**: 数据严重不足,JSON 中已标 TODO 占位,**严禁**编造或从 Baidu Baike 直接拷贝
2. **图片**: 所有 image_urls 字段当前指向 Wikimedia Commons **类目页 (Category:)** 而非具体 File 页。在 Builder 阶段引用图片时,**必须**:
   - 点开类目内具体 File 页面
   - 确认该文件的具体许可标签(CC0 / CC BY / CC BY-SA 各版本)
   - 抓取该文件的"原始作者 / 上传者"并在 demo footer 注明
   - 如某文件无明确 CC 标签或为 "Fair Use"/"Non-free",**禁止使用**
3. **博物馆官网图片**: 所有"current_museum"对应官网,以及 dpm.org.cn / npm.gov.tw / chnmus.net 等机构网,只作事实交叉验证,**不**用其图片
4. **Baidu Baike (baike.baidu.com)**: 仅作信息 cross-check,**禁止**直接复制其文字或图片再分发

### 中风险点
- live2makan 与 daydaynews 等博客文章:可作信息参考,但谨慎引用(博主原创内容可能仍有版权);引用时注明出处
- CGTN / Xinhua / Chinadaily:政府媒体新闻报道中的**事实**可 fair use,**不**直引其图片/长段文字

### 低风险点 (安全使用)
- Wikipedia EN 文本: CC BY-SA 4.0,attribute 即可
- Wikimedia Commons 中明确标 CC0 或 CC-BY 4.0 的图片
- MET Open Access (CC0)
- British Museum (CC BY 4.0)
- UNESCO 文档 (public document)
